## Deliverables

### A. `config/global_targets.json`
- `companies`: list of `{"name","ats":"greenhouse|ashby|lever","slug","category"}` for the 18 above.
  Category examples: robotics, ev-mobility, av, ai-lab, defense.
- `profile_keywords`: weighted terms derived from the profile above, e.g. high weight for
  `motor control, BLDC, PMSM, IPMSM, FOC, SVPWM, inverter, power electronics, actuator,
  motor drive, powertrain, drivetrain, traction`; medium for `embedded, firmware, STM32, RTOS,
  CAN, CAN-FD, state machine, mechatronics, hardware-in-the-loop, HIL, Simulink, FEA,
  reliability, validation, test engineer, DFMEA, APQP, PHM, prognostics, digital twin,
  durability, qualification`; medium for the PM lane `technical program manager, hardware program
  manager, TPM, NPI, new product introduction, DVT, EVT, PVT, supplier quality`.
- `negative_keywords`: terms that disqualify regardless of score — `staff software engineer,
  frontend, backend, full stack, web, recruiter, sales, account executive, marketing, counsel,
  paralegal, accountant, data scientist (unless paired with a hardware term)`, etc. Tune these
  against what the run actually returns and report what you tuned.
- `seniority_exclude`: `director, vp, head of, principal, chief, staff` — the owner has ~3.5 years.
- `min_score`: threshold to keep a posting.

### B. `scripts/global_collect.py`
CLI mirroring the existing collector so the two feel the same:
`python3 scripts/global_collect.py [--config PATH] [--dry-run] [--limit N] [--html] [--telegram]`

Behavior:
- Fetch every company's board. One request per company (these are full-list endpoints — do NOT
  fetch per-posting detail pages; that would be thousands of requests).
- `time.sleep` 1s between companies. A company that errors is logged and skipped, never fatal.
  Exit non-zero only if every company failed.
- Score each posting: sum the weights of `profile_keywords` found in title + department + body,
  with the title weighted more heavily than the body. Drop anything hitting `negative_keywords`
  or `seniority_exclude`. Keep postings at or above `min_score`.
- **Eligibility tagging — this matters more than the score.** For each kept posting derive:
  - `location_raw` and a normalized `country` / `region`.
  - `eligibility`: one of
    - `blocked-itar` — body or company indicates ITAR / export control / security clearance /
      "must be a U.S. person" / "U.S. citizen". The owner is a Korean national; these are closed.
      shield-ai and neuralink are very likely to hit this often — that is expected, not a bug.
    - `visa-needed` — location outside Korea with no sponsorship signal.
    - `sponsorship-likely` — body explicitly mentions visa sponsorship / relocation support.
    - `korea-apac` — the role is in Korea, Japan, Singapore, or APAC.
    - `remote` — explicitly remote-eligible.
  Report the counts per bucket. A blocked posting is still recorded but must be visually separated
  and never ranked above an applicable one.
- State/dedup: `docs/jd/_inbox/global/state.json` keyed by `<ats>:<slug>:<job_id>`, storing
  first_seen / company / title / score / eligibility. Re-running the same day writes no new files.
- Per-posting markdown at `docs/jd/_inbox/global/<company>-<job_id>.md` with YAML frontmatter
  (company, ats, job_id, title, location, country, eligibility, score, matched_keywords, url,
  first_seen) and the JD body as text.
- `--html`: self-contained mobile report at `docs/jd/_inbox/global/report/YYYY-MM-DD.html`,
  same design rules as the existing Wanted report — read
  `docs/jd/_inbox/wanted/report/2026-08-19.html` and match its look so the two reports feel like
  one product. Structure: header (신규 N / 지원가능 M / 누적 T) → **지원 가능** cards ranked by
  score, each showing company, title, location, eligibility chip, matched keywords, score, and a
  JD excerpt → then a collapsed `<details>` for `visa-needed` → then a collapsed, muted
  `<details>` for `blocked-itar` labelled clearly as 지원 불가.
- `--telegram`: send that HTML to the PM bot via `sendDocument`, reading `PM_BOT_TOKEN` /
  `PM_BOT_CHAT_ID` from `/home/window11/project-manager/.env`. Copy the working helper from
  `scripts/wanted_collect.py` — do not reimplement it differently. Missing credentials → warn,
  exit 0. Never print or commit the values.
- Caption: `🌐 글로벌 채용 리포트 YYYY-MM-DD / 신규 N건 (지원가능 M) / 누적 T건`.
