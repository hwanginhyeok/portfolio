## Verified Workday facts — I probed all of these live on 2026-08-19. Do not guess tenants or slugs.

Endpoint shape (POST, JSON):
```
POST https://<tenant>.wd<N>.myworkdayjobs.com/wday/cxs/<tenant>/<site>/jobs
Content-Type: application/json
body: {"appliedFacets":{}, "limit":20, "offset":<n>, "searchText":"<text>"}
```
Response: `{"total": <int>, "jobPostings":[{"title","locationsText","externalPath","postedOn",
"bulletFields"}]}`. The posting URL is `https://<tenant>.wd<N>.myworkdayjobs.com/<site>` + `externalPath`.

Confirmed working tenants — these four and only these four. The others I tried
(asml, lamresearch, continental, teradyne, zf, valeo, borgwarner, magna) returned 404/422:
| tenant | wd | site | Korea-located roles found |
|---|---|---|---|
| `amat` | 1 | `External` | 15+ (Applied Materials — 화성/분당/평택/이천) |
| `kla` | 1 | `Search` | 36+ (KLA — 화성/동탄/평택) |
| `aptiv` | 5 | `Aptiv_Careers` | 9+ (Aptiv — 울산/군포/충주/아산) |
| `micron` | 1 | `External` | 0 (keep configured; it may open later) |

**CRITICAL PAGINATION TRAP**: Workday returns `"total": 0` while still returning a full
`jobPostings` array. A loop that stops when `offset >= total` reads only the first page and
silently under-collects. The counts above are first-page-only for that reason; the true counts
are higher. **Paginate until a page returns an empty `jobPostings` array**, not until `total` is
reached. Cap at 50 pages per tenant as a runaway guard and log when you hit the cap.

Korea location strings are inconsistent across tenants — match case-insensitively on any of:
`Korea`, `KOR`, `Seoul`, `Suwon`, `Hwaseong`, `Icheon`, `Cheonan`, `Pyeongtaek`, `Bundang`,
`Dongtan`, `Gunpo`, `Ulsan`, `Choongju`, `Youngchun`, `Asan`, `Gyeonggi`, `Incheon`, `Busan`.
Real observed values include `Hwaseong-Lucestar,KOR`, `KOR-Gyeonggi-do-Dongtan-KLA`,
`Gunpo-si Gyeonggi-do, Republic of Korea`, and `KOR Asan – MFG`.

Search strategy: query each tenant with `searchText` values that surface Korea plus the owner's
domain — at minimum `"Korea"`, and also a few domain terms (`"motor"`, `"test engineer"`,
`"program manager"`, `"equipment"`, `"quality"`). Union the results by `externalPath`.
Sleep 1s between requests. A tenant that errors is logged and skipped, never fatal.
