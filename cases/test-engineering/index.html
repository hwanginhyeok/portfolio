기초를 쌓다 — 측정 인프라

다이나모미터 토크제어 시스템

스트레인 게이지 풀브리지 + 휘트스톤 브리지 아날로그 처리 + 토크 컨트롤러 FW + 다점 교정. 비선형 브레이크 특성을 보상하는 PID 토크 피드백 제어

쓰임: 이후 모든 성능 시험의 공용 측정 장비로 쓰이도록 설계 — 사내 기술 세미나로 방법 공유

방법론을 확장하다 — 비교 시험 프로토콜

제어 방식 비교 시험 (SVPWM vs DPWM)

온도 조건 매트릭스 · 시료 반복 · 실시간 CSV 로깅 · 통제변수를 고정한 Before/After 비교

쓰임: 제어 방식 선택의 정량적 근거를 만드는 시험 프로토콜

시스템으로 진화하다 — 제품 단위 시험 체계

유체 구동부 성능평가 벤치

유량계 + 압력계 + 배관/밸브/탱크로 구성한 단독 구축 벤치. 시료 간 압력-유량 관계를 같은 조건에서 비교

쓰임: 부품 선정을 "감성 평가"에서 "데이터 기반 선정"으로

송풍부 성능 개선 — 사내 벤치 → 외부 시험기관 검증

독립변수와 통제변수를 분리한 비교 설계. 사내 1포인트 측정에서 외부 기관 다포인트 측정으로 확장

쓰임: 사내 반복성 → 외부 재현성까지 계층적으로 검증하고, 설계 변경의 정량적 근거로 활용

접촉 안전 시험

이론 모델(v²/2a)로 예측하고 접촉 센싱 구간을 설계한 뒤 실기 시험으로 대조

쓰임: 모델 예측과 실측의 차이를 안전 설계에 반영

기준 모델 대비 비교 시험

시판 기준 모델을 빌려 동일 조건에서 주요 서브시스템별로 비교

쓰임: 개선 방향 수립의 근거 자료

내구성 시험 설계

Cycle 기반 수명 시험 계획 · Worst Case 부하 프로파일 · 온도 × 습도 × 지형 조건 매트릭스

쓰임: "프로토타입 동작"과 "양산품 장기 사용"의 차이를 시험 계획으로 메우는 일

패턴 — 단일 장비에서 시스템 시험 체계로

1단계: 단일 장비 제작 (다이나모미터) → 만든 장비가 팀의 측정 인프라가 됨

2단계: 비교 시험 방법론 → 통제변수를 잠그고 Before/After를 숫자로

3단계: 시스템 시험 체계 → 제품 전체를 커버

공개 범위: 시험의 방법과 사용 도구까지. 제품·시험 결과값은 싣지 않는다.
