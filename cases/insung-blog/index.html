네이버 블로그 체험단 자동화 시스템 — 4단계 구축기

왜 만들었나

네이버 블로그 체험단 활동은 단순한 부업이 아니다. 좋아하는 공간을 발견하고, 먹고 경험하고, 그것을 글로 남기는 일이다. 자기만족이기도 하고, 그 글이 누군가에게 도움이 되기도 하고, 수익으로 이어지기도 한다.

그런데 블로그 운영 시간의 상당 부분은 글 쓰는 것이 아니다. 이웃 댓글 달기, 답방, 게시물 올리기 — 이 반복 노동이 "진짜 할 것"을 잠식한다.

반복 노동을 시스템에 넘기면, 블로거는 더 많은 시간을 아날로그 경험과 글쓰기에 쓸 수 있다. 더 좋은 글이 나오고, 생태계가 더 풍요로워진다.

같은 철학, 다른 현장

자율주행 방제기는 농부를 방제 노동에서 해방시킨다. 인성이 시스템은 블로거를 반복 디지털 노동에서 해방시킨다. 자동화의 목적은 기술이 아니라 사람이 해야 할 것에 집중하게 하는 것이다.

4단계 구축

1
댓글봇

이웃 댓글은 블로그 성장의 핵심이다. 그러나 하루 수십 개를 직접 달면 글 쓸 시간이 사라진다.

AI가 상대 블로그 글을 읽고 맥락에 맞는 댓글을 생성. 페르소나(말투·관심사)를 설정하면 일관된 목소리로 활동한다.

Claude Haiku · 페르소나 엔진 · 이웃 답방 스케줄러

2
발행봇

글은 썼다. 그런데 네이버 스마트에디터에 올리는 과정이 또 시간을 잡아먹는다.

사진과 메모만 전달하면 스마트에디터에 자동으로 발행한다. 블로거는 현장 경험에만 집중한다.

Playwright · 스마트에디터 DOM 자동화 · Telegram 트리거

3
Telegram 제어

자동화 시스템은 있는데, 핸드폰으로 상태를 보거나 조작할 방법이 없었다.

텔레그램 하나로 시스템 전체를 제어한다. 이동 중에도 "지금 댓글 돌려"가 가능하다.

Telegram Bot API · Supabase 제어 평면 · FastAPI

4
Chrome 확장

Playwright는 서버에서 네이버에 로그인한다. 네이버가 IP 이중접속을 탐지해 계정 위험이 생겼다.

사용자 브라우저의 Chrome 확장이 직접 행동한다. 서버는 AI 생성과 DB만 담당. IP 문제 근본 해결.

Chrome Extension Manifest V3 · background.js · Vercel API Routes
