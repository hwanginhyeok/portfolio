1. PWM 방식 절환 — 발열과 효율

문제

고온 환경에서 스위칭 소자 발열과 전력 효율 저하를 줄여야 했다.

방법

  • 지령전압 크기에 따라 DPWM과 SVPWM을 절환하는 알고리즘을 단독 개발 (MCU 펌웨어, C)
  • 온도 조건 × 시료 × PWM 방식 매트릭스로 비교 시험을 설계·수행하고, 소자 온도와 입력전력 차이로 방식을 판단 — 과제 완료보고서의 근거 자료
시험 축 설계
환경 온도저·중·고온 영역을 나누어 열평형까지 측정
시료복수 시료로 반복해 같은 경향인지 확인
PWM 방식DPWM ↔ SVPWM, 나머지 조건은 고정
계측회전수·토크·전류·압력·온도 동시 수집 (자체 시험 리그, 실시간 로깅)

2. CAN Sleep/Wakeup 구현

문제

정지 상태에서 배터리 드레인을 막기 위해 암전류(Dark Current) 요구조건을 충족해야 했다.

방법

  • IC + MCU 레지스터 정밀 분석 — CAN 모듈 레지스터 맵, Sleep/Wakeup 시퀀스, 인터럽트 플래그를 데이터시트 기반으로 분석하고 트랜시버 IC 모드 전환 타이밍을 검토.
  • ISO 11898 규격 Wakeup Pattern 구현 — 규격이 정의한 dominant pulse 패턴 기반으로 호환성 확보.
  • Sleep 진입(무통신 타임아웃) → Wakeup 트리거(CAN 수신) → 정상 복귀의 전체 시퀀스를 FW로 구현하고 오실로스코프로 검증.

CAN 프로토콜을 Physical부터 Application Layer까지 이해하게 된 경험이 이후 CAN 다중노드 설계로 이어졌다.

3. 극저온 기동 검증

문제

극저온에서 모터 기동 신뢰성을 확보해야 했다. open-loop 구동에서 closed-loop 구동으로 넘어가기까지의 시간이 길었다.

방법

로터 reference frame 기반 EEMF/BEMF 관측기로 위치·속도 추정, feedforward 포함 위치·속도 추정기로 전환 시간 단축. 본인 역할: 알고리즘의 실험적 검증 담당.

4. 모터 초기위치 검출 — 직무발명 (공동 발명)

문제

센서리스 BLDC 구동에서 로터 초기 위치를 모르면 기동이 불안정하다. 기존 방식은 센서 의존 또는 정밀도 부족.

방법

IPMSM의 위치별 리액턴스 차이를 활용한다. 고주파 신호 주입으로 d/q축 임피던스 비대칭성을 검출해 초기 위치를 추정하고, 오실로스코프로 기동 거동을 확인했다. 선행 논문·특허 조사 → 발명신고 → 출원 절차에 참여. 자세한 내용은 특허 케이스.

다이나모미터 시스템 — 자체 구축

모터 시험을 위한 전용 다이나모미터 시스템을 직접 설계·구축했다. 분리되어 있던 여러 전원을 하나로 통합하고, 히스테리시스 브레이크의 비선형 데드존을 보상하는 하한(Lower limit) + 토크 피드백 PI 제어기를 설계했다. 토크 센서는 스트레인 게이지 브리지로 구성해 다점 교정했고, RS485 통신으로 데이터를 실시간 수집한다.

방법: 데드존 보상 유무 비교 → 토크 응답 오버슈트 비교 → 하한값 확정 (측정값은 싣지 않는다)
