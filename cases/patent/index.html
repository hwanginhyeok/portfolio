직무발명 2건 참여 (공동 발명 1 · 실험 검증 기여 1)

모터 초기 위치 검출 알고리즘

공동 발명

문제

센서리스 BLDC 구동에서 로터 초기 위치를 모르면 기동이 불안정해진다. 기존 방식은 센서에 의존하거나 정밀도가 부족했다.

해결 방법

IPMSM의 위치별 리액턴스 차이를 활용한다. 고주파 신호를 주입해 d/q축 임피던스 비대칭성을 검출하고, 이로부터 초기 위치를 추정한다.

방법: 선행 논문·특허 조사 → 발명신고 → 시험 장비에서 검증

극저온 기동 알고리즘

실험적 검증 기여

문제

극저온 환경에서 open-loop 구동에서 closed-loop 구동으로 넘어가기까지 시간이 길어 기동 신뢰성 확보가 필요했다.

해결 방법과 역할

Back-EMF Observer 기반 능동제어기로 위치·속도를 추정해 전환 시간을 줄이는 방식. 본인 역할은 저온 환경 시험을 설계·수행해 알고리즘을 실험적으로 검증하는 것이었다.

공개 범위: 발명의 주제와 본인 역할까지. 출원 정보와 성능 수치는 싣지 않는다.

현장 문제에서 연구까지

초기위치 검출은 제어기 개발에서 센서리스 구동의 한계를 경험하며 발명했고, 극저온 기동은 국책과제의 저온 요구조건을 만족시키는 연구에서 나왔다.

관련 연구 — 핵심 논문

석사 학위논문 건국대학교 대학원 기계설계학과 · 2023 · 지도교수 김남수

전자기 해석을 이용한 매입형 영구자석 동기 전동기의 고장 진단 시뮬레이션에 관한 연구

Fault Diagnosis Simulation of Interior Permanent Magnet Synchronous Motor using Electromagnetic Analysis

flux-state variable model + FEA로 IPMSM의 자기포화 효과 포함 시뮬레이션. 모터 구동 시스템 + 인버터 제어와 Co-simulation 환경 구축. 다양한 운전 조건에서 실험 검증.

RISS 학위논문 →

키워드: IPMSM · 전자기 해석 · 고장 진단 · Co-simulation · FEA · 자기포화

공저 저널 · IEEE TIM IEEE Trans. Instrum. Meas., Vol. 73, pp. 1-8 (2024-10) · 공저자 오재욱

Programmable Online Bond-Wire Fault Detection and Location Method for Insulated Gate Bipolar Transistor Using Inverter Output Parameters

EV 인버터 IGBT의 본드와이어(bond-wire) lift-off 결함을 게이트 신호/콜렉터 단자 직접 접근 없이 인버터 출력 파라미터(3상 전동기 단자 전압)만으로 검출 + 위치 식별. 본드와이어 단선/열화는 IGBT 모듈 신뢰성의 핵심 결함 모드.

저자: Jaewook Oh, Inhwan Kim, Inhyeok Hwang, Bowook Choi, Namsu Kim (건국대학교)

DOI: 10.1109/TIM.2024.3472910 →
