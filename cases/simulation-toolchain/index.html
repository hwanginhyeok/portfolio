공개 범위: 어떤 도구와 방법을 썼는가까지. 제품 · 사양 · 수치 결과는 싣지 않는다.

한 줄 요약

영상 분석, 이동체 운동 모델, 3D 시각화, 유동 해석 도구를 엮어 "사진 한 장에서 주행 경로를 만들고, 모델이 그 경로를 따라갈 수 있는지"를 실물 시험 전에 확인하는 시뮬레이션 체계를 만들었다.

사용한 도구와 방법

영상 기반 경로 추출

Python · NumPy · SciPy · scikit-image · NetworkX

식생 지수와 방향 정렬 대비로 줄 구조를 찾고, 주기 구조 추출기로 통로 중심선을 만든 뒤 그래프로 연결해 지그재그 경로와 회차 구간을 계획

이동체 추종 시뮬레이션

Node.js · 자체 경량 엔진 · node:test

좌우 궤도 속도 제한·가감속 제한을 둔 차동 구동 운동 모델 위에서 Pure Pursuit 추종기를 닫힌 루프로 실행하고, 회전 가정(제자리 선회·최소 회전 반경)별 민감도를 비교

3D 시각화

Three.js · glTF

시뮬레이션 자세로 3D 모델을 움직이고 경로 · 추종 궤적 · 여유 거리를 겹쳐 보여 주는 웹 뷰어

객체 검출 평가

scikit-image · SciPy(헝가리안 매칭) · SAM 계열 · DeepForest 비교

줄 정보를 이용한 피크 검출기와 기존 분할 모델을 비교하고, 서로 독립된 두 주석의 합의로 기준 정답을 만들어 점 매칭으로 정밀도 · 재현율을 산출

유동 해석

OpenFOAM(Docker) · PyVista

서버 PC와 클라우드 CPU에서 정상상태 비압축 튜토리얼로 해석 환경을 검증하고, 회전체 모델(MRF · actuator disk)의 단계적 적용을 설계

검증 원칙

  • 설정을 먼저 고정하고 평가한다. 평가용 정답은 해시로 봉인한 뒤 한 번만 쓴다.
  • 개발 구역과 시험 구역을 나누고, 시험 구역 결과로 다시 튜닝하지 않는다.
  • 기록된 주행과의 차이는 "불일치"로 보고하며, 자동으로 오차나 안전성 판정으로 바꾸지 않는다.
  • 모든 결과는 모델 · 시뮬레이션 결과로 표기하며 실물 증명으로 쓰지 않는다.
