사진 한 장에서 경로를 만들고, 모델이 따라갈 수 있는지 본다Build a route from one image and see whether a model can follow it

영상에서 주행 경로를 뽑고, 기록된 주행을 재생해 경로 추종을 3D로 검토하는 시뮬레이터를 개발했습니다.I built a simulator that extracts a route from imagery, replays recorded drives and reviews path-following in 3D.

무엇을 하는가WHAT IT DOES

  • 영상에서 주행 경로와 지면 맵을 만든다.Builds a route and a ground map from imagery.
  • 기록된 실제 주행을 재생하고, 제어기 모델과 궤도 차량 추종으로 같은 경로를 따라가 본다.Replays recorded real drives and follows the same route with a controller model and tracked-vehicle path following.
  • 추종 결과를 3D로 겹쳐 본다.Overlays the tracking result in 3D.

판단JUDGEMENT

영상에서 얻은 나무 위치와 경로는 근사값이라, 시뮬레이터는 경로 추종을 미리 살펴보는 모델 검토 도구로 쓴다.Tree positions and routes taken from imagery are approximate, so the simulator is a model-based way to preview path-following.
