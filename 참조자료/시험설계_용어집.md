# 시험 설계 용어집

> 포트폴리오에서 시험/검증 관련 서술 시 참조.
> 정확한 용어 사용이 전문성을 드러낸다.

---

## 변수 체계

| 용어 | 영문 | 정의 | 포트폴리오 예시 |
|------|------|------|----------------|
| **독립변수** | Independent Variable | 연구자가 의도적으로 변화시키는 변수 | 팬 갭(45→9mm), PWM 기법(SVPWM/DPWM), 오일 온도(55/85/125°C) |
| **종속변수** | Dependent Variable | 독립변수 변화에 따라 측정하는 결과값 | 풍속(m/s), FET 온도(°C), 입력전력(W), 정지거리(m) |
| **통제변수** | Controlled Variable | 결과에 영향을 줄 수 있지만 일정하게 고정시키는 변수 | 모터 RPM 단수, 측정 거리/위치, 환경 온도, 배터리 SOC |
| **외란변수** | Confounding Variable | 통제하지 못한 채 결과에 영향을 주는 변수 | 야외 바람, 습도, 지면 경사, 배터리 잔량 변화 |

### 변수 관계도

```
독립변수 ──→ [시스템] ──→ 종속변수
                ↑
          통제변수 (고정)
          외란변수 (최소화)
```

**핵심 원칙**: 독립변수 하나만 바꾸고 나머지는 모두 고정해야 "이것 때문에 저것이 변했다"고 말할 수 있다.

## 시험 구조

| 용어 | 영문 | 정의 | 예시 |
|------|------|------|------|
| **대조군** | Control Group | 변경 전 상태 (기준선) | 기존 갭 45mm, SVPWM 단독 |
| **실험군** | Experimental Group | 변경 후 상태 | 개선 갭 9mm, DPWM 절환 |
| **시험 매트릭스** | Test Matrix | 독립변수 조합의 전수 표 | 3온도 × 2Assy × 2PWM = 12세트 |
| **시험 프로토콜** | Test Protocol | 시험 절차·조건·판정기준 문서 | 농진원 시험 기획서 (DVP) |

## 측정 신뢰성

| 용어 | 영문 | 정의 | 구분 |
|------|------|------|------|
| **반복성** | Repeatability | 같은 사람·장비·조건에서 동일 결과 재현 | 사내 시험으로 확인 |
| **재현성** | Reproducibility | 다른 사람·장비·장소에서도 동일 결과 재현 | 공인 시험장(농진원)에서 확인 |
| **유의성** | Significance | 측정 차이가 오차가 아닌 실제 차이인지 판단 | n이 클수록, 조건 통제가 엄밀할수록 확보 |
| **교정** | Calibration | 측정 장비의 기준값 대비 정확도 확인·보정 | 다이나모미터 10포인트 교정 |

### 사내 시험 vs 공인 시험 — 신뢰성 계층

```
Level 1  시뮬레이션/이론 계산     ← 가설 수립
Level 2  사내 벤치 시험           ← 반복성 확인 (통제 환경)
Level 3  사내 실차/필드 시험      ← 실제 조건 검증
Level 4  공인 시험장 시험 (농진원) ← 재현성 + 공인 인증
Level 5  양산 품질 검증 (SOP)     ← 대량 생산 신뢰성
```

## 데이터 분석

| 용어 | 영문 | 정의 | 예시 |
|------|------|------|------|
| **Before/After** | — | 개선 전후 동일 조건 비교 | 팬 갭 변경 전/후 풍속 |
| **벤치마크** | Benchmark | 비교 기준이 되는 외부 제품/데이터 | RS-500X(기계식) vs GT-SS500(전동식) |
| **사각지대 분석** | Dead Zone Analysis | 성능이 기준 미달인 위치/조건 식별 | 14포인트 중 풍속 미달 5개 → 3개 해소 |
| **민감도 분석** | Sensitivity Analysis | 입력 변화 대비 출력 변화 크기 파악 | 갭 -80% → 풍속 +43~53% |

## 포트폴리오 서술 패턴

### 강한 서술 (추천)
> "14포인트 위치별 풍속 측정을 설계하고, 독립변수(슈라우드 갭)만 변경한 통제 시험으로 +43% 풍속 향상을 **공인 시험장에서 재현**했다."

### 약한 서술 (피해야 할 것)
> "팬을 개선해서 풍속이 좋아졌다."

**차이**: 변수 통제 → 정량적 결과 → 외부 검증의 3단 구조가 있느냐 없느냐.

## 프로젝트별 변수 매핑

### EOP — PWM 절환 시험

| 구분 | 변수 |
|------|------|
| 독립변수 | PWM 기법 (SVPWM vs DPWM) |
| 종속변수 | FET 온도(°C), 입력전력(W) |
| 통제변수 | 오일 온도(55/85/125°C), RPM(2400~3200), Assy 번호(1/2) |
| 시험 매트릭스 | 3온도 × 2Assy × 2PWM = **12세트** |

### SS500 — 팬 성능 시험 (농진원)

| 구분 | 변수 |
|------|------|
| 독립변수 | 슈라우드 갭(45mm vs 9mm) + 프로펠러 직경(22" vs 24") |
| 종속변수 | 위치별 풍속(m/s), 도달 범위 |
| 통제변수 | 모터 RPM 단수(1/2/3), 측정 위치(14포인트 고정), 환경(실내) |
| 시험 매트릭스 | 3단수 × 14위치 × 2조건 = **84회 측정** |

### SS500 — 범퍼 안전 시험

| 구분 | 변수 |
|------|------|
| 독립변수 | 차량 속도(0.5~3.0 km/h, 6단계) |
| 종속변수 | 정지거리(m), 피크전류(A), 정착시간(ms) |
| 통제변수 | 범퍼 스트로크(123.5mm), 차량 중량, 노면 상태 |
| 이론 모델 | s = v²/(2a), a = 0.5167 m/s² |

### SS500 — 펌프 성능평가

| 구분 | 변수 |
|------|------|
| 독립변수 | 펌프 시료(3종: 10.4/13.0/15.6 LPM) |
| 종속변수 | 유량(LPM), 압력(bar) |
| 통제변수 | 모터 RPM, 배관 구성, 밸브 개도 |
| 검증 | 압력-유량 선형관계 규명 |
