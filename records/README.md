# records/

Generated run records for this project: hih-worker runs (conversation, events,
effective config) and input/output packs. Runs land under
`records/runs/<task>/<run>/`; nothing here is hand-edited.

Everything in this directory is git-ignored except this README
(`.gitignore`: `records/*` with `!records/README.md`). Legacy coordination
material, when present, lives at `records/coordination/` on disk only.
