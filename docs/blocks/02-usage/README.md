# B2 — 활용 전략 (HOW TO USE)

> "각 자산을 어떤 메시지의 증거로 쓸지 결정한다. 버릴 것도 결정한다."

## 목적

자산을 나열하는 것과 활용하는 것은 다르다. **메시지가 먼저**, 그 메시지의 **증거**로 자산을 배치한다. 메시지에 매칭 안 되는 자산은 컷.

## 핵심 질문

1. **타겟 회사·직무가 원하는 것은?** (채용공고/JD 분석)
2. **내 커리어 스토리의 핵심 3~5 메시지는?** (예: 시험 주도 / 정량적 임팩트 / 시스템적 사고 / PM 경험 / AI 활용)
3. **각 메시지를 증명할 최강 증거 1~2개는?**
4. **증거로 못 쓸 자산은? 왜?** (컷 리스트)

## 산출물

- [USAGE_STRATEGY.md](USAGE_STRATEGY.md) — 메시지 × 자산 매트릭스

## 매트릭스 골격

```
              | 메시지1 | 메시지2 | 메시지3 | 메시지4 | 메시지5 |
자산 A (C03)  |   ⭐   |        |        |        |        |
자산 B (I02)  |        |   ⭐   |   ✓    |        |        |
자산 C (N01)  |        |   ⭐   |        |        |        |
...
```

- ⭐ = 이 메시지의 핵심 증거
- ✓ = 보조 증거
- 빈칸 = 해당 없음 (컷 후보)

## 컷 기준

1. 10초 룩에서 임팩트 없음
2. 다른 자산이 같은 메시지를 더 강하게 증명함
3. 품질 등급 C이고 가공 비용이 높음
4. 타겟 직무와 무관

## 완료 게이트

- [ ] 핵심 메시지 3~5개 확정
- [ ] 모든 자산이 매트릭스에 배치됨 (사용 / 컷)
- [ ] 컷 리스트에 사유 명시
- [ ] 각 메시지마다 최강 증거 1개 지정
