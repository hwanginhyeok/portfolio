### 2.1 rs500 자율주행 시뮬레이션 — **최우선 승격 대상**

`~/physical_AI_rs500` · 2026-02-19 ~ 2026-08-04 · 67 커밋 · GitHub Actions CI

SS500 궤도형 차량(DB130-48 BLDC 3kW×2, MD2K 듀얼 드라이버, 48V LiFePO4)을 **그대로 모델링**한
Level-2 물리 시뮬레이션 + ROS2 제어 스택.

| 층 | 내용 |
|---|---|
| 순수 Python 코어 (`ad_core`) | ICR 스키드 스티어 운동학 · 뉴턴 동역학(하중전이·경사) · 모터+감속기 1차 지연 + MD2K 가감속 · **MD2K 보호기능(STALL/과전류/과온/과전압)** · **MD2K CAN 코덱** · **Bekker 지면 상호작용** · GPS/IMU 노이즈 · **Dual-EKF 센서 퓨전** · Pure Pursuit · Fields2Cover 커버리지 · 작물행 인식(CV) · LiDAR 장애물 · YOLO 카메라 |
| ROS2 패키지 (7) | `ad_can_bridge` `ad_control` `ad_planning` `ad_perception` `ad_bringup`(Gazebo+Nav2+Foxglove) `ad_interfaces` |
| 도구 | 인터랙티브 L1/L2 시뮬레이터 · 배치 시나리오 러너(3시나리오×5지형) · 모듈별 파라미터 감도 리포트 · MD2K 기능 검증 |
| 검증 | **테스트 파일 19개 / 테스트 함수 497개**, CI 배지 |

**이게 왜 결정적인가.** 4월 전문가 리뷰가 Physical AI·로보틱스 두 도메인에서 가장 큰 갭으로 꼽은 것이
"ROS2 + 인지 스택(SLAM/센서퓨전) + 시뮬레이션(Gazebo, MIL/SIL/HIL)"이었고, 권장 사항이
**"`cases/autonomy-stack/` 신규 케이스 — GT-SS500 차동조향 → Gazebo + nav2 + EKF"**였다.
그게 이미 만들어져 있다. 실제 차량 파라미터로, CAN 코덱까지 붙여서.

현재 `RESUME.md §7.9`의 표기 — "ROS2 · Gazebo · nav2 · turtlebot3 · EKF — 사이드 프로젝트
학습 단계 (정직 기재)" — 는 **이제 과소 기재**다. 정직 기재는 부풀리지 않는 것이지 깎는 것이
아니다.
