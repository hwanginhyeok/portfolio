# B1 — 자료 인벤토리 (WHAT HAVE)

> "가진 패를 다 펼친다". 쓸지 말지는 B2에서 판단. 여기서는 **빠짐없이 나열**이 전부.

## 목적

없는 것을 기다리다가 시간이 녹는다. 있는 것을 먼저 다 펼쳐서 **대기 자산은 대기열로**, 확보 자산은 바로 B2로 보낸다.

## 산출물

- [INVENTORY.md](INVENTORY.md) — 자산 마스터 리스트

## 분류 축

| 축 | 값 |
|----|-----|
| **보유 상태** | 확보 / 대기 / 잠재 |
| **품질 등급** | A (그대로 사용) / B (가공 필요) / C (대체·보충 필요) |
| **유형** | 이미지 / 수치 / 문서 / 경험 / 영상 |
| **출처** | 회사(SS500/EOP/VCU) / 개인 프로젝트 / 대학원 / 외부 |

## 완료 게이트

- [ ] 모든 자산이 INVENTORY에 등록됨
- [ ] 품질 등급 매겨짐
- [ ] 대기 자산은 대기 조건(누가/언제)이 명시됨
- [ ] 잠재 자산은 생성 비용 추정됨
