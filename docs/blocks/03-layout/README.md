# B3 — 배치 (WHERE TO PUT)

> "5섹션 × 섹션 내 순서를 확정한다. 이걸 안 하면 또 엎는다."

## 목적

B2의 메시지·증거가 확정된 뒤, **어디에 어떤 순서로** 배치할지 와이어프레임 레벨로 결정. 구조가 확정돼야 디자인(B4)이 낭비 없이 진행된다.

## 결정 사항

1. **5섹션 골격** — 섹션명, 순서, 역할
2. **섹션 내 순서** — Hero / Body / CTA
3. **페이지 이동 경로** — 홈 ↔ 케이스 ↔ 특허 등
4. **Impact Dashboard 위치** — 최상단? 섹션 간? 별도 페이지?
5. **컨텍스트 스위치** — PC/모바일, 방문자 유형(리크루터/엔지니어)별 첫 화면
