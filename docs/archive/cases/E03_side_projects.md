# Side Projects — 사이드 프로젝트 3종

> "본업의 깊이를 잃지 않으면서, 도메인을 넓힌다."
> 운영 방식: 8개 프로젝트를 단일 PM 시스템으로 통합 모니터링 (E02 참조)

---

## 한 줄 요약

본업(모터제어 / PM)의 시간을 보호하면서, **3개 도메인**(로보틱스 / 데이터 저널리즘 / 금융)의 사이드 프로젝트를 운영 중. 각각의 자세한 케이스는 별도로 작성.

---

## 1. 자율주행 (physical_AI_rs500)

- **도메인**: 로보틱스 / 자율주행
- **스택**: ROS2
- **현재**: HW 블로커로 일시 보류
- **본업과의 관계**: SS500 자율주행 모듈을 회사 자산을 만지지 않고 외부에서 학습/실험할 수 있는 트랙

> 자세한 내용은 별도 케이스로 작성 예정.

---

## 2. 정치통계 (my-politics-stats)

- **도메인**: 데이터 저널리즘 / 콘텐츠
- **스택**: Next.js, Remotion (영상 자동 생성)
- **현재**: cron 운영 중 (큐 정리 / 상태 전환)
- **운영 원칙**: 자동 생성 OK, **자동 게시 금지** — 사용자 승인 후 발행 (게시 승인 게이트)

> 자세한 내용은 별도 케이스로 작성 예정.

---

## 3. 주식분석 (stock)

- **도메인**: 금융 / 시황 분석
- **스택**: Python + cron + systemd
- **현재**: 매일 06:00 / 18:00 시황 브리핑 자동 발행 (네이버)
- **focus_scope**: 테슬라 자동화 (시황 / 리서치 / 아티클)

> 자세한 내용은 별도 케이스로 작성 예정.

---

## 공통 — "어떻게 굴리는가"

8개 프로젝트를 1인이 동시 운영하는 방식은 E02(AI 워크플로우)에서 자세히. 이 케이스는 **"존재하고 있다"**는 사실만 명시하기 위한 인덱스 페이지.
