Overview Job Title: &nbsp; Simulation and Development Engineer, Body Controls &nbsp; About the Team &nbsp; The Body Controls team&nbsp;is responsible for&nbsp;many of the vehicle features customers use every day, including access and security, closures, windows, mirrors, lighting, seating, power management, and diagnostics. The team develops and supports software across multiple ECUs and vehicle platforms, ensuring high-quality customer experiences from development through production and service. &nbsp; This is a highly cross-functional team that works on embedded software development, diagnostics, vehicle integration, supplier management, new hardware bring-up, and production support. The team owns end-to-end delivery of body electronics features across multiple vehicle programs, offering engineers broad technical exposure and significant ownership of customer-facing vehicle functionality. &nbsp; Responsibilities: &nbsp; Develop Unit Tests based on requirements for software components developed to a model-based development lifecycle &nbsp; Create harnesses in Simulink Test and design negative and positive test cases for the software&nbsp;component &nbsp; Develop control systems for vehicle&nbsp;body&nbsp;controls&nbsp;features. &nbsp; Develop requirements and related test cases for access control and other assigned features modeled in&nbsp;Matlab/Simulink. &nbsp; Collaborate with simulation engineers to improve or develop a simulation model/platform to analyze, optimize, and troubleshoot access control and localization algorithms. &nbsp; Assist&nbsp;in the integration of features into the controller code base. Test the developed software on the vehicle and&nbsp;assist&nbsp;in calibration of the features. &nbsp; Learn and contribute to automotive software development lifecycle. From requirements to integration. &nbsp; What You Bring &nbsp; Minimum Qualifications: &nbsp; Bachelor's degree (or higher) in computer engineering, electrical engineering, mechanical engineering, automotive systems, or related technical fields is required. &nbsp; 2+ years of experience with automotive control system&nbsp;design and development,&nbsp;Software-In-Loop (SIL)&nbsp;and Model-In-Loop (MIL) testing &nbsp; Expert knowledge of model-based design and testing using Matlab, Simulink, Stateflow, Polyspace, ModelAdvisor, M-scripting and Simulink Test. &nbsp; Proficiency&nbsp;in&nbsp;C, C++, and Python scripting &nbsp; Experience with&nbsp;industry standard development&nbsp;tools&nbsp;such as&nbsp;JAMA/JIRA/Git/Confluence. &nbsp; Experience in&nbsp;working with cross-functional teams. Creativity in design, hands-on ability, and&nbsp;strong communication&nbsp;skills. &nbsp; Preferred Qualifications: Experience with&nbsp;Automotive Body Control and 12V systems &nbsp; Common understanding&nbsp;of ISO 26262 and&nbsp;Autosar. &nbsp; Experience in designing controllers for electric vehicle systems. &nbsp; Experience with CAN analysis tools like CANalyzer and&nbsp;CANape.
