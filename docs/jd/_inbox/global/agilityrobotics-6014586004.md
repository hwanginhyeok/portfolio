## JD 본문

Agility’s commercially deployed humanoids operate alongside teams in warehouses, manufacturing facilities, and distribution centers—tackling physically demanding and repetitive tasks while enabling workers to focus on higher-value work. With industry-leading safety standards and years of proven deployment data, we're pioneering a new era of automation that enhances human potential. About the Role Agility Robotics is seeking a hands-on test technician to support daily workflow and regression testing for our humanoid robots. This role involves operating robots in structured test scenarios, running automated scripts, and capturing results to support ongoing software and hardware development. About the Work Execute daily robot test workflows using established procedures Run and monitor Python-based test scripts (basic to moderate proficiency expected) Set up and manage test network connections (Ethernet, switches, IP configuration) Work within a Linux environment using bash shell commands and scripting Log issues and test outcomes using Jira Follow directions precisely, including written procedures, verbal instructions, and informal guidance Assist with general lab and test support tasks as needed Aim is to achieve &gt; 4 hours of daily workcell operation with both happy path and corner cases to uncover failure modes. About You Associate’s degree or equivalent certifications&nbsp; in network administration, system administration or industrial controls &amp; automation Familiarity with Ethernet and basic networking Comfortable using Linux and bash shell Experience with Jira or similar issue tracking tools Strong attention to detail and ability to follow evolving test procedures Willingness to take on other duties as assigned Location This is an onsite position at our Fremont office.
