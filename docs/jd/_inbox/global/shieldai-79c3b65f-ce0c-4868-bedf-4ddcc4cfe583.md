Shield AI is a venture-backed defense-tech company with the mission of protecting service members and civilians with intelligent systems. Its products include Hivemind autonomy software, V-BAT and X-BAT aircraft, and Aechelon simulation and synthetic reality technologies. With offices and facilities across the U.S., Europe, the Middle East, and Asia-Pacific, Shield AI’s technology actively supports operations worldwide. For more information, visit www.shield.ai. Follow Shield AI on LinkedIn, X, Instagram, and YouTube. We are seeking Autonomous Software Engineers for full-time roles starting in 2027! This is a paid, in-person, full-time position for students graduating during the 2026-2027 academic year. We are now reviewing applications for positions starting after graduation in 2027. What you'll do Design, implement, test, and ship C++ and/or Python features, tools, and tests alongside experienced engineers. Write embedded firmware in C/C++ for real-time software that controls our advanced UAV while in flight. Develop tests, reporters, and tooling in Python to validate software behavior and performance. Develop and evaluate autonomy software across areas such as mission behavior, planning, multi-agent coordination, decision-making, platform integration, or perception (object detection, tracking, sensor fusion, localization, situational awareness, or AI/ML-enabled workflows). Build unit and integration tests, run and analyze simulation or bench results, and investigate failures using logs, telemetry, traces, and debugging tools. Support software integration across autonomy capabilities, platform/vehicle interfaces, sensors, perception products, mission compute, and operator or command-and-control (C2) systems, including simulation, software-in-the-loop, hardware-in-the-loop, and bench testing. Work with real and simulated data from cameras, EO/IR sensors, IMUs, GPS, radars, or other mission payloads. Work cross-functionally with electrical and mechanical engineers to help determine and validate software requirements. Write documentation for setup steps, interface assumptions, configuration, test procedures, and findings to make workflows repeatable. Participate in code reviews, design discussions, and test debriefs, and take on more ownership of features and fixes over time.
