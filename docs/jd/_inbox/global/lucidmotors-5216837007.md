That means refusing to choose between performance and sustainability, design and engineering, ambition and integrity. In Lucid Air and Lucid Gravity, we have designed and built vehicles that have redefined their segments, combining exceptional range, performance, design, and expansive space in a single experience. &nbsp; We achieve this through deep vertical integration, with design, engineering, and production&nbsp;happening in-house&nbsp;across our global offices and&nbsp;manufacturing&nbsp;facilities.&nbsp;Our&nbsp;teams&nbsp;come&nbsp;from&nbsp;industries&nbsp;around the world, united by a shared commitment to excellence.&nbsp;By refusing to settle, you&nbsp;can&nbsp;help&nbsp;redefine&nbsp;what’s&nbsp;possible and&nbsp;shape the future of mobility. The Role &nbsp; Join Lucid’s Autonomous Driving and ADAS organization to develop and&nbsp;maintain&nbsp;the ADAS Integration Applications. You will integrate active safety, driving&nbsp;assistance, parking, viewing, and driver-monitoring functionality across multiple vehicle programs and software variants. This role blends embedded application development, ADAS feature integration, software architecture, build infrastructure, and cross-functional coordination and collaboration. &nbsp; The successful candidate thrives with minimal guidance, makes sound technical decisions, and turns complex system requirements into robust,&nbsp;adaptive&nbsp;and reliable production software in a fast-moving environment. &nbsp; What&nbsp; You’ll &nbsp;Do &nbsp; Design, develop, and&nbsp;maintain&nbsp;production&nbsp;ADAS application-layer software in C++ for the ADAS Integration Application.&nbsp;Partner with project management, feature owner, system, validation,&nbsp;infotainment&nbsp;and ADAS development teams to deliver production-ready ADAS features. &nbsp; Analyze and decompose system-level requirements into clear software requirements; Own software architecture, complete implementation tasks, and support verification criteria definition. &nbsp; Design and implement robust state-machine logic for active safety, parking, viewing, and driving features. &nbsp; Implement vehicle-facing feature behavior, including telltales, notifications, warnings, chimes, settings, diagnostics, fault handling, and HMI interactions. &nbsp; Integrate supplier and in-house ADAS functionality across existing and future vehicle programs and software variants. &nbsp; Develop and&nbsp;maintain&nbsp;communication interfaces using various middleware and communication protocols such as DDS and Ethernet. &nbsp; Build scalable multi-platform software architecture, code-generation workflows, and release strategies that support common code across vehicle programs. &nbsp; Contribute to Bazel-based build systems, CI/CD pipelines, build automation, developer tooling, and code optimization. &nbsp; Participate in code reviews, design reviews, release planning, documentation, and continuous improvement of engineering workflows &nbsp; Perform unit, SIL, HIL, bench, and in-vehicle testing; troubleshoot integration issues and lead root-cause analysis across software and ECU boundaries. &nbsp; . &nbsp; Requirements &nbsp; Bachelor’s degree in Computer Science, Computer Engineering, Electrical Engineering, or a related field, or equivalent practical experience. &nbsp; 5+ years of professional&nbsp;software-development&nbsp;experience, including embedded, automotive, robotics, or other safety-critical systems. &nbsp; Strong C/C++ programming, software architecture, debugging, and system-integration skills in Linux-based development environments. &nbsp; Demonstrated experience designing and implementing state machines and translating complex requirements into testable software. &nbsp; Experience with Git-based development, code reviews, automated builds, and modern CI/CD workflows. &nbsp; Ability to work independently, communicate clearly, and collaborate effectively across software, systems, and validation teams. &nbsp; Preferred Qualifications &nbsp; Master’s or PhD degree in Computer Science, Computer Engineering, Electrical Engineering, Robotics, or&nbsp;a related field. &nbsp; ADAS/AD, HMI, or&nbsp;vehicle application&nbsp;integration experience. &nbsp; Experience delivering the full production lifecycle: requirements, design, implementation, unit testing, SIL/HIL, vehicle validation, release, and field support. &nbsp; Experience with&nbsp;functional safety&nbsp;development, including ISO 26262 concepts and safety-critical application integration. &nbsp; Hands-on experience with QNX&nbsp;or&nbsp;comparable embedded automotive platforms. &nbsp; Experience with&nbsp;middleware communications&nbsp;and ECU network tools such as Vector&nbsp;CANoe&nbsp;or&nbsp;CANape. &nbsp; Experience with Bazel,&nbsp;CMake, code generation, build-server infrastructure, CI/CD optimization, and multi-platform release branches. &nbsp; Experience with MATLAB/Simulink, simulation-based validation, diagnostics, fault handling, logging, and vehicle data analysis. &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp; &nbsp;
