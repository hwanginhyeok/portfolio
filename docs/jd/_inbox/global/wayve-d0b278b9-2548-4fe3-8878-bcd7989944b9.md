Before the detail, here's the challenge you'd help us solve. We build the embodied intelligence that moves real vehicles safely, and the ecosystem a billion machines will run on in the future. Very few people in AI can say this. Every role here, whatever the team, plugs into that. Here’s what this particular role covers. 🛠️ About our Engineering Teams As a Senior Embedded Software Engineer on the Onboard Test Automation Team at Wayve, you will play a key role in validating onboard software systems before they reach full-vehicle testing. You’ll work across a range of embedded compute platforms and operating systems to ensure software is reliable, integrated, and ready for real-world deployment. This is a high-impact role where your work directly improves software quality and enables faster iteration across multiple teams. You’ll help scale testing by building automated tests and empowering developers to validate their work earlier in the development cycle. 🧠 Your day-to-day - Design, develop, and execute automated tests for onboard software subsystems (OS, middleware, sensors, and integration points) - Validate software behavior on embedded hardware platforms within hardware-in-the-loop environments - Collaborate with software engineers to identify test gaps and build coverage for new and existing features - Debug and triage system-level issues across software and hardware boundaries - Enable developer self-service testing by contributing to CI pipelines and reusable test frameworks - Support expansion of test coverage by leveraging existing validation tests and shifting them earlier in the development cycle 🧩 What you’ll be working on - Automated integration and system-level testing for embedded Linux or QNX software. - Hardware-in-the-loop validation across multiple compute platforms. - Reliability checks for sensor pipelines, middleware, timing, latency, data integrity, and dropped messages. - Observability that makes intermittent failures easier to reproduce and diagnose. - Earlier validation of software changes to reduce risk during full-vehicle testing. - Test frameworks that improve developer velocity and confidence across Robot Software. 🙌 You should apply if - You have experience testing embedded software systems, ideally on Linux or QNX. - You can develop automated tests in Python, C++, or a similar language. - You have hands-on experience with embedded hardware and hardware/software interactions. - You can debug complex system-level problems using logs, metrics, and controlled experiments. - You understand automation, integration testing, and system validation principles. - You are comfortable collaborating across software, hardware, and infrastructure teams. Experience with HiL environments, sensor or data pipelines, CI/CD systems such as Buildkite, robotics, autonomous systems, or real-time software would be valuable. 🌱 Not ticking every box? That’s totally okay! If you’re passionate about autonomy and keen to learn, we encourage you to apply even if you don’t meet every requirement.
