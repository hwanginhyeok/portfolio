Job Description: As a Simulation Framework Engineer (L1) on the Simulation Framework Team, you will help develop and maintain the software that connects modeling and simulation (M&S) environments with core autonomy software. You will work alongside experienced engineers to write C++ and Python code, build adapters and plugins, and support reusable software components that reduce the simulation-specific complexity exposed to autonomy developers. This is a hands-on software engineering role intended for an early-career engineer who is interested in defense simulation, autonomy, distributed systems, and technical integration. You will contribute to simulation environments and frameworks such as NGTS, AFSIM, Aechelon, HMSSimBlocks, and the emerging Hivemind Simulation Framework (HMSF). You will support the team’s migration of HMSSimBlocks capabilities to HMSF by helping implement baseline adapters, port selected modules, test functionality, and maintain compatibility for programs that continue to use HMSSimBlocks.
