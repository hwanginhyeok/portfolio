## 소개

[ 웨어러블에이아이 소개 ]
웨어러블에이아이는 공항, 리조트, 항만, 조선소, 공장 등 다양한 이동 주체가 얽혀 움직이는 SPM(Special-Purpose Mobility, 특수목적모빌리티) 환경에 맞춰,
AI 월드모델 기반 인식·예측, Proactive Driving, 독립적인 Safety Architecture, 자체 설계한 로봇을 하나로 결합해, Plug-and-Play 방식의 풀스택 로보틱스 플랫폼을 만듭니다.

[직무소개]
본 포지션은 SPM 환경의 자율주행 모빌리티가 목표 지점까지 안전하고 부드럽게 이동할 수 있도록 Motion Planning 및 Control 알고리즘 개발에 참여하는 역할입니다.
현재 알고리즘과 개발 환경을 이해하고, 시뮬레이션과 실차 테스트를 통해 문제를 발견하며, Far subgoal과 주변 상황 변화에 즉각 반응하는 Reactive Local Planning, 파라미터 튜닝 업무를 단계적으로 맡게 됩니다.
로봇, Control, 소프트웨어 개발의 기본기를 바탕으로 실제 차량에서 발생하는 문제를 꾸준히 관찰하고 개선해갈 분을 찾고 있습니다.

## 주요업무

1. 모션 플래닝 및 Control 모듈 구현 지원
• World Model이 출력하는 Occupancy/Intention Prediction과 Far Subgoal을 입력으로 받아, 매 순간 반응형으로 Local Path를 생성하는 Reactive Local Planner 관련 기능 구현 지원
• 4륜 독립 조향(4WIS)·4륜 독립 구동(4WID) 플랫폼의 넓은 Action Space를 활용하는 Motion Primitive 및 Trajectory 생성 로직 구현 지원
• 팀에서 정의한 알고리즘 구조와 인터페이스를 바탕으로 C++ 및 Python 코드 작성
• ROS 2 기반 Node와 Message 구조 이해 및 수정
