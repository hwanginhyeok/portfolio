## 주요업무

에듀테크 플랫폼(LMS)과 가상훈련(실감형) 학습 콘텐츠를 아우르며, 학습자가 '무엇을, 어떤 순서로, 어떻게 배울지'를 설계하는 기획 업무를 담당합니다. 웹 서비스 기획을 중심으로, 가상훈련(실감형) 학습 콘텐츠 기획까지 하나의 흐름으로 이어서 진행합니다.

• 학습 플랫폼(LMS) 서비스 기획 — IA·정책·사용자 흐름 설계, 화면설계서·기능정의서·요구사항 정의서 작성
• 국내외 사용자를 고려한 플랫폼 구조 및 다국어·현지화 요소 설계
• 학습자·교수자·관리자 등 다중 사용자 구조와 권한 설계
• 가상훈련(실감형) 콘텐츠의 학습 목표·학습자 분석을 기반으로 한 컨셉 및 학습 흐름(UX) 설계
• 가상훈련(실감형) 콘텐츠의 학습 시나리오·스토리보드·기획서 작성
• 콘텐츠 제안서 작성 및 테스트를 통한 학습 효과 검증·개선
