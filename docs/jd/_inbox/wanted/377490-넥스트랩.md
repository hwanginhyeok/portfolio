## 소개

nextlab은 산업 현장의 복잡한 데이터를 정밀하게 측정하고, AI로 의미 있는 인사이트로 전환하는 B2B AI 솔루션 전문기업이에요.

 사업 영역은 크게 두 가지로, 통신 품질을 정밀하게 테스트하는 Industrial Test & Measurement와 AI 에이전트 기술을 기업 업무에 접목하는 Enterprise AI Agent가 있어요.

 nextlab의 제품은 이미 시장에서 성과로 증명됐어요. 통신 품질 테스트 디바이스 netMeter는 국내 누적 7천 대 이상 납품되었고, X-Ray 이물질 탐지 장비는 기술력을 인정받아 식품의약품안전처 AX-Sprint 정부 사업을 수행하고 있어요. 단순한 하드웨어 회사가 아니라 AI, 소프트웨어, 하드웨어가 결합된 제품을 설계부터 양산까지 직접 만들어가는 기술 조직이에요.

 이번에 채용하는 분은 nextlab의 제품에 적용되는 영상처리 엔진과 AI 검사 기술을 개발하고 개선하는 역할을 맡아요. 실제 제품과 검사 환경에서 이미지 데이터를 수집·선별하고 직접 라벨링하며, 객체 탐지·이상 탐지 모델을 실행해 결과를 분석하게 돼요. 모델의 오탐과 미탐 원인을 찾아 데이터와 영상처리 엔진을 개선하는 과정에도 함께 참여해요.

 데이터 수집과 라벨링은 단순한 보조 업무가 아니에요. 어떤 데이터를 수집해야 하는지 판단하고, 일관된 기준으로 정답 데이터를 구축하며, 모델 결과를 다시 데이터와 제품 개선으로 연결하는 AI 개발의 핵심 과정이에요. Python과 OpenCV를 활용한 영상 전처리·후처리부터 모델 학습과 결과 분석까지 컴퓨터 비전 개발의 전체 흐름을 경험할 수 있어요.

 처음부터 모든 영상처리 기술과 AI 모델을 알고 있을 필요는 없어요. Python으로 데이터를 다뤄본 경험이 있고, 이미지 처리나 머신러닝 프로젝트를 한 번이라도 끝까지 수행해 봤다면 충분해요. 기존 코드와 모델을 직접 실행하고 실제 제품 데이터를 살펴보면서 업무 범위를 단계적으로 넓혀갈 수 있어요.

 nextlab은 이런 분과 함께하고 싶어요.

 결과가 예상과 다를 때 표면적인 현상보다 근본적인 원인을 하나씩 확인하는 분, 모르는 기술을 직접 찾아보고 실행하며 배우는 과정을 즐기는 분, 맡은 일을 끝까지 책임지고 더 나은 방법을 고민하는 분과 함께하고 싶어요. 진행 상황과 어려운 점을 동료들과 편하게 공유하고, AI와 소프트웨어 기술을 실제 제품의 성능 개선으로 연결하는 데 관심이 있는 분을 찾고 있어요.
