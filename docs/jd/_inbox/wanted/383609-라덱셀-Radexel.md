## 소개

[이 ​포지션의 ​핵심]

모터·센서·PLC·I/O·계측기 ​등 다양한 장치를 ​제어 SW로 ​연결하고, ​실제 방사선치료기가 ​정해진 조건과 ​순서에 ​따라 안정적으로 동작하도록 만드는 ​역할입니다.

라덱셀은 암 ​환자의 방사선치료 부작용을 줄이고 치료 효과를 높이기 위해 자기장 기반 정밀 제어 방사선치료 기술인 MPRT(Magnetic Precision Radiation Therapy)를 개발하고 있습니다.

MPRT 시스템은 모터, 센서, I/O, PLC, 계측기 등 다양한 장치가 하나의 시스템으로 연결되어 동작하는 대형 의료장비입니다. 현재 초기 개발 단계로, 장비 구성과 Interface 및 요구사항이 지속적으로 구체화되고 있습니다.

이 포지션은 장치의 통신 Interface부터 Status·Alarm·Fault 처리, State·Sequence·Interlock 로직까지 구현하고, 이를 EPICS 및 Application과 연동해 코드가 실제 장비의 동작으로 이어지도록 만드는 역할입니다. 보드나 MCU를 새로 개발하는 펌웨어 직무도, 웹·백엔드 중심의 일반 Application 개발 직무도 아닙니다. 실제 장비를 코드로 제어하고, 현장에서 발생하는 문제를 직접 확인·해결해 본 개발 경험을 중요하게 봅니다.

## 주요업무

• 모터 드라이버·센서·I/O·PLC·계측기 등 다양한 장치를 제어 SW와 연동
• Serial·TCP/IP·RS-485·Modbus·CAN·EtherCAT 등 다양한 장치 통신을 구현
• Command·Status·Alarm·Fault 정보를 정의하고 제어 SW와 연동
• EPICS IOC/PV 및 Application에서 장치 상태를 확인하고 명령을 실행할 수 있도록 구현
• 장비의 State·Sequence·Interlock·Fault·Recovery 로직을 구현
• 실제 장비에서 발생하는 통신·모터·I/O 문제를 재현하고 디버깅
• 전장·펌웨어·기구 담당자와 Interface 및 장비 동작 조건을 협의하고 테스트·검증 결과를 문서화
