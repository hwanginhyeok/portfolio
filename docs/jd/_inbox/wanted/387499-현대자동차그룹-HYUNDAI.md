## 소개

우리 조직은 완성차 조립 공정에 휴머노이드 로봇을 실제 투입·운영하기 위한 RF(Robot Friendly) 시스템과 로봇-현장 시스템을 잇는 핵심 미들웨어를 개발합니다. 단순 연동을 넘어, AI Agent 기반의 지능형 운영 체계를 통해 로봇이 예외 상황을 스스로 판단하고 대응할 수 있는 자율적 운영 솔루션을 구축하는 업무를 수행합니다.

## 주요업무

• 로봇-현장 시스템 연계 아키텍처 설계: 로봇과 현장 설비-운영 시스템 간 데이터-제어 흐름을 정의하는 상위 연계 아키텍처 설계
• 시스템 간 역할과 책임 경계를 정의하고, 신규 로봇·설비 추가 시 재사용 가능한 표준 인터페이스 구조 수립
• 이기종 통신 방식(HTTP/gRPC/TCP/IP/Modbus 등)을 표준 규격으로 변환·통합하는 Adapter 미들웨어 개발
• AI Agent 기반 지능형 운영 체계 개발: 작업 실패, 예외 상황(자재 결품, 인식 오류 등) 발생 시 원인을 판단하고 대안을 제시하는 AI Agent 로직 개발
• 로봇 상태/작업 이력/현장 데이터를 기반으로 작업 재할당, 우선순위 조정 등을 자율적으로 수행하는 오케스트레이션 레이어 구축
• LLM/생성형 AI를 활용한 이상 상황 분석 및 담당자 알림, 의사결정 지원 기능 개발
• 안전·품질·작업지시 신뢰성 확보: 산업안전 표준(ISO 13849, IEC 61508 등) 기반 위험 감지 및 자동 긴급정지 기능 구현
• 서열/조립 작업 오더 정보를 로봇 작업지시로 변환하고, 작업 결과를 품질 시스템과 연동하는 신뢰성 확보 로직 개발
• 실시간 작업 상태·이벤트 기반 모니터링 및 알림 체계 구축
• 현장 적용 전 통합 검증: 실제 현장 시나리오(예외 상황, 통신 단절 등) 기반 통합 테스트 및 검증 수행
• 가상 데이터 기반 사전 검증(Mock/Simulator)으로 현장 도입 리스크 최소화

## 자격요건

• 이공계(전자, 제어, 정보통신공학, 로봇, 컴퓨터, 소프트웨어) 분야에서 학사 이상의 학위를 보유하신 분
• 5년 이상의 로봇/자동화 시스템 미들웨어·플랫폼 개발, 또는 통신 프로토콜 표준화 경험을 보유하신 분
• 비즈니스 영어 커뮤니케이션 및 문서 작성 역량을 보유하신 분
• 소켓 프로그래밍, 비동기 통신, 메시지 큐 등 통신 구조 전반에 대한 이해도를 보유하신 분
• 로봇 HW/SW 개발자와 좌표계, 제어 주기 등 로봇 엔지니어링 기반 기술 소통 경험을 보유하신 분
