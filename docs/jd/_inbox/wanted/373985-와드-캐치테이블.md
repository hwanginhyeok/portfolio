- 작은 클릭 하나까지 데이터 기반 실험과 반복 개선을 통해 경험의 밀도를 높이며, Part Lead와 PM이 문제를 정의하고 실험을 주도해 고객의 탐색·발견 경험을 지속적으로 진화시킵니다.
