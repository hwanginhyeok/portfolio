## 소개

이숲(Esoop)은 이커머스의 가치를 잇는 숲입니다. 스마트스토어·쿠팡·자사몰 등 온라인 스토어를 재무실사부터 계약까지 안전하게 거래하는 이커머스 M&A 플랫폼으로, 이미 매물 거래·인수/매각 프로세스·자체 데이터 분석 엔진을 운영하고 있습니다. (TIPS 선정, 매쉬업벤처스 투자유치)

우리는 IM(인수제안서) 자동생성, 실사 프로세스의 디지털 전환 등 M&A의 비효율을 기술로 풀어왔습니다. 매물 관리부터 딜 파이프라인, 실사, IM까지 한 건의 거래를 이루는 기능이 많고, 그 하나하나를 단단하게 만들고 운영해 줄 사람이 필요합니다. 팀 전체가 AI 에이전트를 개발 도구로 쓰고 있어, 기능 하나를 처음부터 끝까지 맡아 완성하는 방식으로 일합니다.

맡은 기능을 끝까지 완성하는 풀스택 엔지니어를 찾습니다.

## 주요업무

• 이커머스 M&A 플랫폼 '이숲'의 웹 서비스 프론트엔드·백엔드 기능 개발 및 유지보수
• 백오피스 기능 개발 — 매물 관리, 딜 파이프라인, CRM 자동화, 고객 행동 데이터 수집 및 분석
• IM 자동생성, 실사 자동화 등 LLM 기반 제품 기능의 구현과 안정화
• 기획된 기능을 일정 안에 완성도 있게 구현하고, 배포 후 운영·개선까지 책임

## 자격요건

• 맡은 기능을 기획부터 개발, 배포, 운영까지 끝까지 완성해 본 경험
• AI 에이전트(Claude Code, Cursor 등)를 개발 도구로 활용해본 경험 — 결과물을 스스로 검증하고 책임질 수 있는 분
• SQL과 관계형 데이터베이스에 대한 기본 이해, Git 기반 협업 경험
