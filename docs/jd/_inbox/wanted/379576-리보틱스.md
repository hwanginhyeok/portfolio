## 소개

최고의 성능, ​극강의 ​강건성, 그리고 ​안정성을 모두 갖춘 ​로봇 시스템을 ​함께 ​만들어갈 엔지니어를 ​모십니다.
복잡한 ​제약 ​환경에서 멀티 로봇의 ​경로·트래픽·스케줄링을 ​최적화하고, AI·데이터 기반 ​알고리즘을 ​설계해 ​시뮬레이션부터 실제 로봇 ​환경, 상위 ​시스템 ​연동까지 FMS(Fleet ​Management System) ​전 ​영역을 함께 만들어갈 ​엔지니어를 찾습니다.

## 주요업무

• 멀티로봇 경로 최적화 및 MAPF 문제 해결: Multi-Agent Path Finding(MAPF) 알고리즘을 설계·구현하고, 다수 로봇이 동시에 이동하는 환경에서 충돌·교착상태(Deadlock)·병목 구간을 예방하는 안전하고 효율적인 경로·자원 할당 로직을 개발합니다.
• 스케줄링 알고리즘 개발: 다양한 작업 요구사항과 제약 조건을 고려한 최적화 스케줄링 알고리즘을 설계·구현하고, 실시간 데이터를 활용해 예측 및 스케줄링을 개선하는 로직을 개발합니다.
• 상위 시스템 인터페이스 연동: WMS/MES 등 상위 시스템, 로봇 제어 시스템과의 통신 인터페이스를 설계·구현하며, VDA5050, MQTT, OPC UA 등 산업용 통신 프로토콜을 활용해 안정적인 연동 구조를 만듭니다.
• 성능 검증 및 튜닝: 시뮬레이션 환경과 실제 로봇 환경에서 알고리즘 성능을 검증하고 지속적으로 최적화합니다.
• 운영 지원: 현장에 적용된 FMS/스케줄링/트래픽 제어 시스템에서 발생하는 문제를 분석하고 개선합니다.
