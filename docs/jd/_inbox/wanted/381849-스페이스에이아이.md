## 소개

스페이스에이아이는 로봇이 물체를 보는 것을 넘어 얼마나 세게 다뤄야 하는지까지 학습할 수 있도록 Physical AI용 Force/Stress 데이터 인프라를 만듭니다.

실제 물체의 힘·변형을 측정하고, 물리 시뮬레이션을 실측에 맞게 보정한 뒤, RGB·Depth·Force·Stress가 정렬된 학습 데이터를 생성하고 실제 로봇에서 검증합니다. GIST 기반의 AI·로보틱스 연구 네트워크와 대규모 GPU 연구 환경을 바탕으로 물리 시뮬레이션, 로봇 학습, 실험계측을 연결하고 있습니다.

로봇을 활용한 연구·개발 경험을 바탕으로 데이터와 알고리즘의 가치를 실제 로봇 실험으로 검증할 동료를 찾습니다. 로봇 인지·학습·제어·조작 등 다양한 연구 경험을 환영하며, 본인의 강점을 바탕으로 시뮬레이션과 실로봇 검증을 연결합니다.

근무: 서울 가산 오피스 주 5일, 10:00~19:00. 실험·검증을 위해 필요 시 광주 GIST 실험팀과 출장·협업합니다.
