## 소개

AI로 꿈을 안전한 현실로 만든다 ─ 아이넵(INEB)

아이넵은 데이터가 생성되고, 흐르고, 저장되는 모든 순간을 보호하는 데이터 보안 기술 기업입니다. DB 암호화와 통합 키 관리로 금융·공공 등 가장 엄격한 엔터프라이즈 환경에서 신뢰를 쌓아왔고, 지금은 데이터 보호의 다음 기준을 만들고 있습니다.

• 지금 집중하는 기술 : 실시간 로그 파일 암호화, 변경 데이터 기반 DB 개인정보 검출, 서버 개인정보 검출·마스킹
• 다음 시대를 준비하는 기술 : 양자내성암호(PQC, Post-Quantum Cryptography: 양자컴퓨터로도 해독하기 어려운 차세대 암호), 차세대 통합 키 관리(KMS, Key Management System: 암호 키를 일원화해 관리하는 시스템), AI 기반 보안 제품

이제 코드는 AI가 씁니다. 우리가 찾는 사람은 그 코드를 지휘하고, 검증하고, 책임지는 사람입니다.

아이넵 개발 조직은 AI를 개발 프로세스의 기본값으로 사용합니다. 설계 검토부터 코드 생성, 리뷰, 테스트, 문서화까지 여러 AI 에이전트가 함께 일합니다. 아이넵이 말하는 'AI 네이티브 개발자'는 코드를 직접 쓰기보다 설계하고(아키텍트), AI를 지휘하고(지휘자), 결과를 검증하고(검증자), 끝까지 책임지는 개발자입니다.

## 주요업무

• 보안 솔루션(에이전트 / 정책 서버 / 데이터 처리 엔진)의 아키텍처 이해 및 기능 설계
• 설계 문서를 기반으로 AI 코딩 도구에 구현 지시, 결과물 리뷰·보완
• AI 생성 코드 검증 (가장 중요한 업무)
  - 핵심 로직·예외 처리·보안 취약점·성능 문제 분석
  - 단위 테스트·통합 테스트 설계·작성·자동화
  - 테스트 결과를 근거로 "왜 이 코드가 맞는지" 설명하고 책임지는 품질 관리
• 관리 콘솔 UI(사용자 화면), 대용량 데이터 테이블·차트·대시보드, 정책 설정 화면 개발
• 어드민 API(프로그램 간 연동 규격), Linux/Unix 멀티 플랫폼 대응
• 멀티 에이전트 기반 설계-구현-리뷰-테스트 워크플로우 개선 및 팀 검증 기준 수립 참여
