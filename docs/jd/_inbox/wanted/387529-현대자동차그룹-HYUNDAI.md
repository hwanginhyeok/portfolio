• 현실 세계에서 유연하고 강건하게 동작하는 알고리즘 개발을 위해 AI 모델들을 연구하고 우리의 목표 로봇과 테스크에 맞게 개선

• 3D 비전 AI 기반 객체 인식 알고리즘 개발
• 타겟 물체 6DoF Pose, Grasp Pose 추정 AI 알고리즘 개발
• 물체 적재 위치 추정 알고리즘 개발
• 로봇 객체 및 환경 인식 알고리즘 개발
• Visual Prompt 기반 타겟 물체 검출 AI 알고리즘 개발
• 물체조작을 위한 공간 인식 AI 알고리즘 개발
• 비전 AI 알고리즘 양산화 설계
