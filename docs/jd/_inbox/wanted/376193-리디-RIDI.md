## 소개

리디의 정보보안팀은 임직원이 어디서 일하든 안전하게 일할 수 있는 환경을 만들고, 고객과 회사의 소중한 데이터를 지키는 것을 목표로 합니다. 위협을 사전에 예방하고, 빠르게 탐지·대응하며, 사고의 근본 원인을 구조적으로 개선해 다시는 같은 문제가 반복되지 않도록 합니다.
정책 문서에 머무르지 않고 시스템과 자동화로 풀어내는 것을 지향하며, AI·에이전트를 실제 보안 운영에 능동적으로 활용해 팀의 대응 속도와 커버리지를 넓혀가고 있습니다.

## 주요업무

• 임직원 PC·서버 등 모든 종단기기(엔드포인트)의 위협 라이프사이클을 책임집니다.
• 제로트러스트 2.0 수준에서 예방·탐지·대응·재발 방지에 이르는 전 과정을 설계·운영하고, 이슈의 근본적 해결과 구조적 개선을 진행합니다.
• EDR·MDM을 연계한 디바이스 신뢰 기반 접근통제를 설계·운영하고, 위협 탐지·로그 분석·침해사고 대응(IR) 체계를 고도화합니다.
• N2SF 수준의 계정 인증체계와 중요데이터 처리 권한을 설계·운영하며, 데이터 등급에 따라 인증 강도와 접근권한을 차등 적용합니다.
• 보안 운영 자동화를 설계·구현하고, AI·에이전트를 실제 보안 운영에 능동적으로 투입합니다

## 자격요건

• 인하우스 정보보안 실무를 3년 이상 경험하신 분(엔드포인트·계정·데이터 보안 등)
• EDR, MDM, IdP(SSO/MFA) 중 하나 이상을 직접 운영·정책 설계해 보신 분
• MFA, 최소권한, 권한 분리(SoD), 데이터 등급별 접근통제 등 계정 인증·권한 관리를 설계해 보신 분
• 제로트러스트 아키텍처를 이해하고 실제 환경에 적용해 보신 분
• 클라우드(AWS 등) 보안 기본 원리를 이해하고 있는 분
• AI 도구를 활용해 반복 업무를 자동화 프로세스로 설계할 수 있는 분
• 기술 배경을 다른 동료에게도 눈높이에 맞게 설명·설득할 수 있는 커뮤니케이션 역량을 보유하신 분

## 우대사항

• 프롬프트 인젝션·에이전트 보안 등 AI·LLM 보안에 대한 경험 또는 관심이 있고, AI를 보안 운영에 활용해 보신 분
• 침해사고 대응(IR), 위협 헌팅, XDR, 다크웹·위협 인텔리전스를 활용해 보신 분
• Win/Mac 환경의 엔드포인트 보안 위협을 관리해 보신 분
• SASE / DLP / CNAPP를 도입·운영해 보신 분
• ISMS-P / ISO 27001 / 개인정보보호법(PIPA) 대응 실무를 경험하신 분
