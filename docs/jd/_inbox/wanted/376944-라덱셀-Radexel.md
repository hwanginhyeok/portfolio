## 소개

라덱셀은 암환자에 대한 방사선 치료의 부작용을 줄이고 효과를 높이기 위해, 세계 최초로 자기장 기반 정밀 제어 방사선치료기(Magnetic Precision Radiation Therapy, MPRT)를 개발하는 스타트업입니다.

이 포지션은 여러 상용 장치와 제어 모듈을 하나의 방사선치료기 제어 시스템으로 통합하고, 자신이 구현한 제어 SW가 실제 치료 장비의 정밀하고 안정적인 동작으로 이어지도록 만드는 역할입니다. 보드나 MCU를 새로 개발하는 저수준 펌웨어 직무가 아니라, 모터·센서·I/O·PLC·계측기 등의 장치 매뉴얼과 통신 사양을 바탕으로 상태값, 명령값, 알람, 인터락 조건을 설계하고 제어 SW·EPICS·Application에서 장비가 실제로 동작하도록 구현합니다.

## 주요업무

• 상용 모터 드라이버, 센서, I/O, PLC, 계측기의 통신 인터페이스 구현 (Serial, TCP/IP, RS-485, Modbus, CAN, EtherCAT)
• 장치별 상태값, 명령값, 알람값, Fault Code 정리 및 제어 SW 연동
• EPICS IOC/PV 및 Application 화면에서 장치의 상태를 확인하고 명령을 실행할 수 있도록 연동
• Idle -＞ Ready -＞ Running -＞ Fault -＞ E-stop 등 장비 운전 상태 흐름 구현
• 대전 테크센터 내 장비 테스트 환경에서 통신, 센서, 모터, I/O 이슈 재현 및 수정
• 필요 시 MCU/펌웨어 담당자와 통신 프로토콜, 상태, 알람 구조 협의

본 포지션에서 구현한 제어 SW는 곧바로 장비의 물리적 동작으로 나타납니다. 모터, 센서, I/O, PLC, 계측기, Application, EPICS가 하나로 연결되는 장비 통합의 전 과정을 직접 경험하게 됩니다.
