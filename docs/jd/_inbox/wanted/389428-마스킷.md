## 소개

[AI-NATIVE SI · PROJECT LEAD]
AI 시대의 SI 수행 방식을 만들고 실제 시장에서 증명할 PM/PL을 찾습니다.
제안서 작성부터 요구사항 정의, 에이전트팀 운영, 검수와 납품까지 전 과정을 주도합니다.

■ 회사 소개
마스킷은 LG전자 사내벤처에서 스핀오프한 B2B SaaS 스타트업입니다. 모바일 티켓 SaaS 큐리스(Qless)를 통해 예매·발권·검표·데이터 활용의 전체 과정을 제공하며 중소벤처기업부 TIPS 과제를 수행하고 있습니다.
자체 티켓 기술과 소프트웨어 에이전트 수행 체계를 기반으로 문화예술기관의 홈페이지·회원·티켓 시스템 구축 사업을 추진하고 있습니다.

■ 이 역할의 미션
이미 정해진 방법론을 운영하는 자리가 아닙니다. 실제 사업을 수행하며 AI 기반 SI의 새로운 수행 표준과 성공사례를 만드는 첫 번째 SI Project Lead입니다.
• 초기에는 대표이사가 PM을 맡고 Project Lead가 PL로서 요구사항·실행·품질·검수를 주도합니다.
• 사업 상황에 따라 제안 PM, 프로젝트 PM 또는 PL로 역할이 달라집니다.
• 프로젝트 수는 고정하지 않으며 난이도와 단계에 따라 담당 범위를 조정합니다.
• 직함보다 필요한 역할을 맡아 제안부터 납품까지 사업을 끝내는 것을 중요하게 생각합니다.

■ 권한은 역량만큼 빠르게 넓어집니다
처음부터 모든 책임을 혼자 떠안는 자리는 아닙니다. 대표이사는 계약·예산·중대 변경과 핵심 고객관계를, CTO는 기술 아키텍처와 개발 품질을 책임집니다. 에이전트팀은 코드와 문서 초안을 생산하고 문서 디자이너가 시각적 완성도를 지원합니다.
• 합의된 범위 안에서 고객 실무 의사결정과 일정·우선순위를 직접 결정합니다.
• 완료조건을 충족하지 못한 에이전트 산출물의 재작업을 요구하고 품질 Gate를 통제합니다.
• 역량 검증 후 중소형 사업을 단독 PM으로 맡습니다.
• 본인이 만든 수행 방식을 회사 표준으로 채택하고 후속 프로젝트에 적용합니다.
• 사업 확장 시 복수 프로젝트 운영과 후속 인력·파트너 구조 설계까지 역할을 넓힙니다.

■ 이런 분에게 특히 잘 맞습니다
• 중소 SI 또는 웹에이전시의 실무형 PL로 일했고 제안과 독립 PM까지 범위를 넓히고 싶은 분
• 기존 프로세스를 운영하기보다 자신의 수행 방식을 회사 표준으로 만들고 싶은 분
• AI를 문서 작성 도구가 아니라 프로젝트 생산성과 품질을 높이는 실행체계로 활용하고 싶은 분
• 성과를 입증한 만큼 빠르게 의사결정 권한을 갖고 싶은 분

## 주요업무

1. 제안·입찰 기획과 제안서 작성
• RFP의 참여 조건·요구사항·평가항목·위험 분석
• 수주전략, 핵심 메시지와 제안 스토리라인 수립
• 수행·기술·관리·일정·인력·품질·보안·검수 계획의 제안서 원고 작성
• 페이지별 콘텐츠와 시각화 요구사항 정의, 문서 디자이너 결과물 검수
• 제안 발표자료, 스크립트, 예상 질의응답과 증빙자료 준비

2. SI 프로젝트 수행
• 고객 실무회의, 회의록, 자료요청과 후속조치 운영
• WBS, 마일스톤, 위험·이슈·의사결정·변경 대장 관리
• 고객 요구를 기능·정책·데이터·화면·비기능 요구사항과 수용기준으로 구조화
• 에이전트 작업 분해·배분, 중간 산출물 검토와 재작업 통제
• 사용자 인수시험(UAT), 결함 재검증, 교육·인수인계, 검수·납품 총괄

3. 수행 방법론 자산화
• 제안·요구사항·테스트·보고·납품 템플릿 표준화
• 실제 투입공수, 재작업, 고객 결정 지연과 결함 데이터 기록
• 후속 사업을 더 적은 인간 공수로 수행할 수 있도록 프로세스 개선
