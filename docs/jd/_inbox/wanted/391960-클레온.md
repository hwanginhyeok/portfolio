## 소개

Klleon은 실시간 대화형 디지털 휴먼 기술을 기반으로 글로벌 기업, 대기업, 공공기관과 다양한 B2B 프로젝트를 진행하고 있습니다.

Technical Program Manager는 고객 요구사항을 실제 개발 Task와 Deliverable로 구체화하고, App / Backend / Platform / Infra / AI 조직과 협업하여 프로젝트가 일정과 품질에 맞게 완료되도록 관리하는 역할입니다.

직접 개발하는 포지션은 아니지만 Software Development, System Architecture, Infrastructure에 대한 충분한 이해를 바탕으로 개발팀과 기술적으로 논의할 수 있어야 하며, 복잡한 기술 내용을 문서, Architecture Diagram, 제안서, 보고서, Presentation으로 구조화할 수 있어야 합니다.

## 주요업무

일정 및 Dependency 관리
• WBS, Milestone 및 개발 일정 관리
• App / Backend / Platform / Infra / AI 조직 간 Dependency 조율
• 프로젝트 Risk / Issue / Blocker 관리

Requirement 관리
• 고객 요구사항 분석 및 Requirement 관리
• 요구사항을 개발 Task와 Deliverable로 구체화

프로젝트 관리 및 QA / Release 관리
• Android / Web / Backend / SDK / CMS Integration 프로젝트 관리
• 기능별 Acceptance Criteria 및 QA Checklist 정의
• End-to-End 기능 QA 및 Latency, Stability, Loading Time 등 성능 검증
• Release / Deployment 및 고객 검수 관리

문서 및 커뮤니케이션
• 기술 제안서, 구축계획서, 보고서 및 고객 제출자료 작성
• PowerPoint / Google Slides 기반 Presentation 작성
• 고객 미팅 및 Action Item 관리

Infra / Architecture
• Cloud / Network / Security 요구사항 Coordination
• Infrastructure / System / Network Architecture Diagram 작성

## 자격요건

• Software / Cloud / Infrastructure 관련 TPM, Technical PM, Solution Architect, Technical Consultant 또는 유사 업무 경력 3년 이상
• Software 개발 프로세스, System Architecture 및 Frontend / Backend / API / SDK Integration 구조에 대한 이해를 바탕으로 개발자 및 Infra Engineer와 기술적으로 논의할 수 있는 분
• 프로젝트 일정, Risk, Issue 및 Dependency 관리 경험
• 고객 요구사항을 Task / WBS / Acceptance Criteria로 구조화할 수 있는 능력
• 기술 문서, 고객 제안자료, Architecture Diagram, Presentation을 논리적으로 작성하고, 기술적인 내용을 고객이 이해할 수 있는 언어로 설명할 수 있는 능력

## 우대사항

• Software / Backend / App / Infra Engineer 경험 또는 개발자에서 TPM / Solution Architect로 역할을 확장한 경험
• Android App, Web Application, Backend / API / SDK Integration 프로젝트 경험
• Cloud / Infrastructure 환경 경험 (AWS, Naver Cloud, Kubernetes 등)
• 기능 / 성능 QA 및 End-to-End Test 수행 경험
• 금융사 / 공공기관 / 대기업 프로젝트 경험 (SI 구축·검수, 보안성 검토 대응 등)
• RFP / RFI 및 기술 제안서 작성 경험
• AI / Generative AI 기술에 대한 기본적인 이해
