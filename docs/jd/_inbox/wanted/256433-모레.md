## 주요업무

• 다양한 GPU 아키텍처를 대상으로 최적의 커널 코드를 생성, 선택하기 위한 코드 생성기와 오토 튜너 개발
• AI 애플리케이션에 특화된 GPU의 구성 요소들(행렬 곱셈 유닛, GPU 간 고속 인터커넥션 등)을 활용
• GPU 간의 효율적인 통신 라이브러리 개발, 이는 서로 다른 노드에 위치한 GPU 사이의 통신을 포함
