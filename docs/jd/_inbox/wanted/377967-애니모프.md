## 소개

ㅣ회사 소개

“AI가 브랜드를 발견하고 추천하는 방식을 다시 만듭니다.”

Anymorph는 AI 검색 최적화 기술, GEO(Generative Engine Optimization)를 만드는 엔지니어 중심의 스타트업입니다.

사람들은 이제 Google만 검색하지 않습니다. ChatGPT, Claude, Gemini에게 무엇을 살지, 어떤 서비스를 사용할지 묻습니다. 기업은 검색 결과의 첫 페이지를 넘어 AI의 답변 안에서 발견되고 추천되어야 합니다.

Anymorph는 브라우저 자동화 기술을 통해 여러 AI 엔진에 하루 수만 번 질문하고, 브랜드가 어떻게 인식되고 인용되는지 분석합니다. 분석 결과를 바탕으로 AI가 참고할 수 있는 콘텐츠를 기획하고 생성하고 배포하며, 다시 성과를 측정합니다.

단순히 데이터를 보여주는 SaaS가 아닙니다. AI가 실제 업무를 수행하는 Service-as-a-Software를 만듭니다.

서울대학교 공대와 Microsoft·AWS 출신들이 지난해 미국에서 Anymorph를 창업했습니다.

• 창업과 동시에 실리콘밸리 VC로부터 프리시드 약 10억 원 유치
• 서비스 출시 3개월 만에 미국 프리유니콘 스타트업으로부터 약 200억 원 규모의 Acqui-hire 제안
• 출시 6개월 만에 글로벌 대기업과 K-Beauty 대표 브랜드 5곳 이상을 고객으로 확보
• 식품, 타이어, 가구 분야 대기업이 실제 업무에 사용
• 이 모든 것을 5명 이하의 소수 정예 팀으로 달성

ㅣ직무 소개

Anymorph의 Product Engineer는 정해진 기획서를 전달받아 기능을 구현하는 개발자가 아닙니다.

고객이 겪는 문제를 직접 이해하고, 필요한 제품을 설계하고, 배포하고, 실제 결과까지 확인합니다. 프론트엔드, 백엔드, 인프라의 경계를 나누기보다 문제 해결에 필요한 기술을 빠르게 익혀 적용합니다.

“좋은 코드를 넘어 실제 고객 가치를 만드는 제품을 끝까지 책임지는 엔지니어”
