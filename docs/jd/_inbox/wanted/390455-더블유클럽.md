## 소개

[ About 더블유클럽 ]

더블유클럽(W Club)은 2019년부터 '실제 만남'에 집중해 온 프리미엄 매칭 서비스입니다. 가입비 수백만 원의 결혼정보회사가 하던 일을 모바일로 옮겼습니다.

누적 만남 111,735건(2026년 7월 기준), 애플·구글 누적 다운로드 30만 회 이상. 하이엔드 매칭 앱 업계 최초로 TV CF를 진행했고, 서울 시내 버스 광고도 진행했습니다. 많은 데이팅 앱이 채팅과 과금에 집중할 때, 더블유클럽은 실제 만남에 집중합니다. 경제력 서류 인증과 간편 인증으로 신뢰를 검증하고, 만남보장 정책으로 약속부터 만남까지 책임집니다.

[ 우리가 자랑하는 가치 ]

• 7년째 운영 중인 실서비스 : 실제 사용자와 데이터 위에서 일합니다. 내 작업이 바로 숫자로 확인됩니다.
• 함께 성장하는 동료 : 최고의 복지는 최고의 동료라는 말이 있어요. 우리는 개인의 성장을 장려하고 지원하며, 구성원 모두가 서로의 든든한 뒷배가 될 수 있는 환경을 구축합니다.
• 소통과 회고를 통한 성장 : 명확한 결정과 행동의 추진력을 얻기 위해 매월 우리의 성취를 돌아봅니다. 회고를 통해 성과는 함께 기뻐하고, 아쉬움은 앞으로를 위한 발판으로 삼습니다.

## 주요업무

이 포지션은 이렇게 일합니다.

• 우리 회사는 대표와 PO가 AI로 작동하는 기능을 매일 만들어 냅니다. 만드는 속도는 이미 빠릅니다. 이 자리는 그 결과물이 실서비스에 안전하고 빠르게 들어가도록 기술 구조와 반영 과정을 책임지는 자리입니다.
• 직접 코드를 쓰는 것보다 "무엇을, 어떤 순서로, 어떻게 안전하게 올릴지" 판단하는 일이 더 중요합니다. 본인도 AI(Claude Code 등)로 개발하고, 다른 사람과 AI가 만든 코드를 검토해 운영 서버 반영을 결정합니다.
• 운영 서버, 운영 DB, 배포 권한을 책임집니다. 장애가 나면 가장 먼저 원인을 찾고 되돌릴지 고칠지 정합니다.
• 대표 직속이며, 엔지니어 채용과 개발 방식 정립에도 참여합니다.

[주요업무]
• 서비스 전체 기술 구조 설계와 개선 (서버, DB, 앱, 관리자 도구)

• 반영 과정 정립: 개발 서버, 스테이징, 운영 서버 단계와 배포 주기, 새 기능을 꺼 둔 채 올리는 방식 등
• 운영 DB 안전 변경, 모니터링, 장애 대응과 되돌리기 기준 운영
• 보안과 권한 관리: 개인정보 보호, 접근 권한 최소화, 외부 작업자 권한 관리
