## 소개

어쎈드는 글로벌 매크로와 퀀트 트레이딩을 위한 AI 기반 리서치 시스템을 만들고 있습니다.

우리가 만들고 있는 것은 단순한 챗봇이나 리포트 생성 도구가 아닙니다. 데이터 수집, 가설 생성, 근거 탐색, 반박, 검증, 기록, 의사결정 지원까지 이어지는 리서치 과정을 하나의 신뢰 가능한 시스템으로 바꾸는 일입니다.

이 시스템은 더 많은 텍스트를 생성하기 위한 것이 아니라, 더 좋은 질문을 던지고, 근거 없는 결론을 걸러내고, 판단 과정을 추적 가능하게 만들며, 리서치 기록이 자산으로 축적되도록 하기 위한 시스템입니다.

이 포지션은 LLM API를 호출하거나 프롬프트를 다듬는 역할에 그치지 않습니다. 불확실한 AI의 출력과 복잡한 리서치 workflow를 명확한 상태, 검증 가능한 흐름, 재현 가능한 시스템으로 바꾸는 역할입니다.

우리는 현재 개발 중인 AI research system을 더 견고하고 확장 가능한 인프라로 발전시킬 사람을 찾고 있습니다. 단순히 기능을 이어 붙이는 사람이 아니라, 무엇을 만들고 무엇을 만들지 않을지 판단하며 시스템의 구조를 함께 설계할 사람을 찾습니다.

## 주요업무

• AI 기반 금융·시장 리서치 workflow를 설계하고 고도화합니다.
• 질문 정의, 데이터 수집, 가설 생성, 근거 검토, 반박 검증, 기록, 의사결정까지 이어지는 리서치 흐름을 시스템화합니다.
• 여러 AI agent와 도구가 예측 가능하고 검증 가능한 방식으로 협업할 수 있도록 실행 구조를 설계합니다.
• Agent별 역할, handoff 기준, task 완료 조건, tool 사용 범위, 실패·timeout 처리 방식을 정의합니다.
• AI가 생성한 결과의 출처, 근거, 수치 정확성, 반대 근거, 재현 가능성을 검증하는 레이어를 구축합니다.
• 리서치 과정에서 저장해야 할 상태, 로그, 중간 산출물, 검증 기록을 정의합니다.
• 사람이 개입해야 하는 지점과 자동화 가능한 지점을 구분해 Human-in-the-loop 구조를 설계합니다.
• 단순 기능 구현보다 오래 유지되고 개선될 수 있는 AI research system 구조를 만듭니다.
