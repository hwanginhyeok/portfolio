## 소개

자사 AI 모델을 활용하여 실제 사용 가능한 AI 서비스를 개발합니다. 학습·평가 데이터의 생성과 품질관리부터 모델 연동 및 운영, 프론트엔드와 백엔드 개발까지 AI 서비스의 전체 생명주기를 함께 담당합니다.
단순히 AI가 생성한 코드를 조합하는 것이 아니라, 서비스 구조를 이해하고 코드를 검토·검증하며 안정적으로 운영할 수 있는 개발자를 찾습니다.

## 주요업무

• 자사 AI 모델을 활용한 웹 기반 AI 서비스 설계 및 개발
• 프론트엔드, 백엔드, API 및 데이터베이스 구축
• AI 모델 추론 API 연동 및 입출력 처리 로직 개발
• 학습·평가 데이터 생성, 검수, 정제 및 버전 관리
• 데이터 구축 기준과 품질관리 프로세스 수립 및 개선
• 데이터 오류 및 모델 결과 분석을 통한 개선 방안 도출
• 데이터 파이프라인 및 반복 작업 자동화
• 모델 버전, 평가 결과, 배포 상태 및 성능 지표 관리
• 임상 전문가, 고객사 및 내부 개발 조직과의 협업
• 데이터 구축 가이드라인, 기술 문서 및 산출물 작성

## 자격요건

• 경력 무관
• 약 2년 이상의 소프트웨어 개발 학습 또는 프로젝트 경험
• Python 또는 JavaScript/TypeScript를 활용한 개발 경험
• 프론트엔드와 백엔드의 기본 구조를 이해하고 서비스를 직접 구현해 본 경험
• REST API, 데이터베이스 및 Git을 활용한 개발 경험
• 머신러닝 모델과 학습·평가 데이터 생명주기에 대한 기본적인 이해
• AI가 생성한 코드를 직접 검토하고 디버깅할 수 있는 역량
• 새로운 도메인을 빠르게 학습하고 전문가와 협업하여 요구사항을 구체화할 수 있는 분
• 자신의 개발 과정과 기술적 의사결정을 명확하게 설명할 수 있는 분

## 우대사항

• AI 기능이 포함된 서비스를 처음부터 배포까지 개발한 경험

• AI 모델 서빙, 평가 또는 모니터링 경험

• 데이터 파이프라인 또는 Data Engine 구축·운영 경험
• Docker, 클라우드, CI/CD 환경 경험
• 대규모 학습데이터 구축 또는 데이터 품질관리 경험
• 의료·임상 데이터 관련 프로젝트 경험
