## 소개

■ 팀스파르타의 ​Security ​Solutions ​Engineer를 소개해요
 "전사 ​200명의 보안, 그 체계를 ​직접 ​세워갑니다."
 • 팀스파르타는 매출 ​600억, 영업이익 100억 ​규모의 국내 ​SW·AI ​교육 1위 ​기업으로 ​빠르게 ​성장해왔습니다. 조직이 커지고 ​전사 ​차원의 AI 전환이 ​가속화되는 ​지금, ​사내 보안 체계를 ​한 단계 ​고도화할 ​시점에 있습니다. ​그 중심에 ​있는 ​팀스파르타 개발팀은 IT ​커리어 성장의 ​전 과정에서 필요한 사용자 경험 설계와 백오피스 시스템 운영을 책임지고 있습니다. 최신 기술 트렌드를 적극적으로 수용하면서도 서비스 신뢰성과 유지보수성을 함께 고려하는 균형잡힌 기술 선택을 지향합니다.
 • 팀스파르타 Security Solutions Engineer는 개발팀에 소속되어 전사 200여 명이 사용하는 전체 보안 환경을 강화하는 역할을 담당합니다. 단말·네트워크 보안 솔루션 운영, 보안 정책 수립, 인프라 구축·관리까지 사내 보안 체계의 A to Z를 다루며, 보안 체계 전반을 만들어가고 있습니다.
 • 이미 완성된 체계를 유지보수하는 자리가 아닌, 팀스파르타만의 보안 체계를 직접 설계하고 만들어가는 자리에서 변화에 맞는 보안을 함께 만들어갈 엔지니어를 찾습니다.


■ 함께 할 동료의 한 마디
"안녕하세요, 개발팀 팀장 이동현입니다. 팀스파르타 전체의 보안을 책임지는 Security Solutions Engineer를 찾고 있습니다. 정보 보안과 비즈니스 사이의 균형감을 갖고, 빠르게 다양한 시도를 함께 할 동료를 기다리고 있어요. 새로운 시도에 열려있는 기술 조직, 자동화에 진심인 비즈니스 조직과 함께 팀스파르타만의 보안 체계를 만들어가고 싶습니다.”


■ Security Solutions Engineer는 이런 성장을 할 수 있어요
 • 보안 분야 8년 이상의 시니어 엔지니어와 함께 팀스파르타의 보안 체계를 A to Z로 직접 설계하며, 단순 운영을 넘어 기획과 정책 수립까지 주도적으로 이끌 수 있습니다.
 • 빠르게 성장하는 조직에서 발생하는 다양한 보안 이슈를 선제적으로 해결하며, 규모 확장에 따른 보안 아키텍처 설계 경험을 쌓을 수 있습니다.
 • 자동화에 진심인 비즈니스 조직, 새로운 시도에 열린 기술 조직과 협업하며 보안 엔지니어의 시야를 비즈니스 전반으로 확장할 수 있습니다.
