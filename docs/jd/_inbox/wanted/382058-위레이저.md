## 소개

AI는 똑똑히졌지만, 아직 `일`은 못 합니다.
데이터는 넘쳐도 AI가 곧바로 행동에 옮길 수 있는 데이터는 없습니다.
위레이저는 그 빈자리를 채웁니다.

1. 우리는 데이터를 AI가 즉시 행동하는 데이터(AI Action Data)로 바꾸는 표준 단위, Domain Fractions를 만듭니다.
2. 우리는 특정 도메인 회사가 아닙니다. 반도체, 항공, 금융, 커머스, F&B 등 산업을 가리지 않습니다.
3. 지금 우리 안에는 300개 이상의 에이전트가 실제 업무를 처리하고 있습니다.

이 포지션은 새로 만드는 자리가 아니라 이미 만들어진 제품을 관리하고, 발전시키고, 알리고, 수익으로 바꾸는 자리입니다.

## 주요업무

• 제품의 로드맵과 우선순위 관리: 할 일과 하지 않을 일을 근거와 함께 결정
• 고객 사용 데이터와 피드백 기반의 제품 개선: 사람이 결과를 다시 확인하는 시간을 줄이는 것
• 제품 성과를 시장의 언어로 전환: 케이스 스터디·홈페이지·세일즈 자료·데모 시나리오 직접 작성
• 가격·패키징·갱신·확장 전략 수립과 제품별 성과 지표 관리
• 이탈·미갱신의 원인 분석과 개선 결과의 수치 입증
