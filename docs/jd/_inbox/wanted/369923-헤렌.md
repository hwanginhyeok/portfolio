[헤렌에서의 QA 엔지니어]
공비서의 QA는 제품의 품질과 배포 안정성을 책임지는 역할을 담당합니다.
매장 원장님의 운영(예약·결제·고객관리·마케팅)이라는 복잡한 도메인 위에서, 앱(iOS/Android)과 웹에 걸친 테스트 자동화 체계를 0에서 직접 설계하고, AI를 품질 검증 프로세스로 풀어내는 경험을 하게 됩니다. 테스트를 작성하는 사람을 넘어, 무엇을 어디까지 자동화할지 기준을 만드는 환경에서 한 단계 더 성장할 수 있는 토양을 제공합니다.
구체적으로는 이런 일을 하게 됩니다:

01. 테스트 자동화 체계 설계와 구축
멀티플랫폼(앱/웹) 자동화 프레임워크를 직접 설계·구축하고, 배포 전 자동화 통과를 게이트로 두는 구조를 만들어 운영합니다.
이미 각 플랫폼별로 아래 기술셋으로 테스트 자동화를 구축중에 있습니다. QA 엔지니어는 이를 TC 기반으로 더 고도화하고 웹프론트, 네이티브 개발자들과 협업합니다
• Android : Maestro (YAML 플로우) + UIAutomator
• iOS : Maestro + XCUITest
• 웹프론트 : playwright

02. AI 기반 품질 검증 설계
AI를 활용한 테스트 케이스 생성, 결함 예측·분석, 자동화 스크립트 작성 보조를 실제 QA 프로세스에 적용하고, 그 방식을 직접 설계합니다.

03. AI를 활용한 QA 방식 개선
Claude Code, Cursor 등의 도구를 활용해 테스트 작성, 시나리오 정리, 반복적인 검증 작업을 줄이는 방향으로 QA 프로세스 자체를 개선합니다.

04. 품질 기준과 배포 안정성 정립
자동화 커버리지·실패율·회귀 결과를 데이터로 가시화하고, "배포해도 되는가"를 판단하는 기준을 만들어 팀 단위로 확장합니다.

속도와 품질 사이에서 상황에 맞는 결정을 내리는 능력을 중요하게 봅니다.
