## 소개

파일러니어는 전력 데이터를 수집하는 스마트미터를 직접 개발하고, 장치 내부(엣지)에서 데이터를 분석하는 IoT 스타트업입니다. 전기차 충전기 모니터링 등 실제 현장에 장치를 설치하고 운영하고 있습니다.
파일러니어의 미션은 탄소중립을 위한 지속가능한 에너지 생활 환경을 만드는 것이며, 전력 모니터링을 통해 숨어있는 문제를 찾고 해결하는 것을 비전으로 삼고 있습니다.

전력 데이터 속에 숨어있는 문제를 찾으려면, 먼저 데이터를 정확하게 수집하는 기기가 있어야 합니다. 이 포지션은 스마트미터의 하드웨어와 펌웨어를 중심으로, 데이터 수집부터 분석까지 제품의 핵심을 직접 만드는 역할입니다.
처음부터 모든 영역을 다룰 필요는 없으며, 역량에 맞는 영역에서 시작하여 점차 범위를 넓혀갑니다.

## 주요업무

• 전력 데이터 수집용 IoT 기기 하드웨어 개발
• 임베디드 펌웨어 개발: 데이터 수집, 엣지 연산, 서버 전송
• 현장 설치 장치의 테스트, 디버깅 및 안정화
• (확장) 이상탐지·시계열 예측 등 데이터 분석 알고리즘 개발

## 자격요건

• 데이터를 수집하고 전송하는 IoT 기기를 직접 설계·제작해본 경험 (업무·개인·연구 프로젝트 포함)
• C/C++ 또는 Python 기반 임베디드 개발 경험
• 모르는 영역을 스스로 학습해 동작하는 결과물로 만들어본 경험

• 학부 연구생, 석·박사 등 이공계 연구 프로젝트 경험
