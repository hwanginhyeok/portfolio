## 소개

•회사 소개
테파로보틱스는 Human demonstrator에 의해 생성된 120만 에피소드 이상의 Action 데이터를 자체 생성 및 보유하고 있으며, B200x8 1노드, H100x8 2노드, A6000x8 1노드를 이용해 Action 모델을 학습하고, FANUC 산업용 로봇 3대, FANUC 협동 로봇 3대를 통해 테스트할 수 있는 환경을 보유하고 있습니다. 이를 기반으로 실제로 산업적인 가치를 창출할 수 있는 VLA 기반의 로봇 제어 소프트웨어 개발을 진행합니다. 

구인중인 VLA 엔지니어 포지션은 로보틱스에 대한 백그라운드보다도, Multimodal 데이터와 모델에 대한 이해도가 높으신 분들이 적합하며 아래와 같은 경험을 하실 수 있습니다.
• 실제 산업 환경 문제를 직접 해결하는 VLA 모델 개발
• 자체적으로 수집한 대규모 로봇 데이터 기반 VLA 학습 및 모델 구조 설계
• VLA를 위한 데이터 생성 파이프라인 개발
• VLA 모델 패키징 및 암호화, 경량화
