특히 올해는 소상공인과 공공 분야로 사업 영역을 넓혀, 사회적 가치와 기술 혁신을 동시에 추구하고 있습니다.

• 빠르게 변화하는 시대에 맞춰, 데이터와 AI로 새로운 가능성을 만들어갑니다.

! 함께하면 좋은 이유 !

## 주요업무

• Python을 기반으로 AI/ML 모델을 개발하고 서비스에 적용합니다.
• LightGBM, XGBoost 등을 활용하여 수요 예측 및 매출 예측 모델을 개발하고 성능을 개선합니다.
• LangChain 또는 LangGraph를 활용하여 AI Agent를 설계하고 개발합니다.
• Vector DB를 활용하여 RAG 시스템을 설계·구축하고 검색 및 답변 성능을 개선합니다.
• 데이터 전처리, Feature Engineering, 모델 학습 및 평가 과정을 수행합니다.

## 자격요건

• 1년 이상의 Python 기반의 AI/ML 애플리케이션을 개발 경험
• LightGBM, XGBoost 등 머신러닝 모델을 학습 / 평가 경험
• LangChain 또는 LangGraph 기반 AI Agent를 개발
• Vector DB를 활용하여 RAG 시스템을 구축
• PostgreSQL, MySQL 등 RDB를 이해하고 SQL을 활용하여 데이터를 조회·가공

## 우대사항

• DeepAR, TFT, Transformer 등을 활용하여 시계열 기반 수요 예측 또는 매출 예측 모델을 개발 경험
• P10/P50/P90 등 확률적 예측(Probabilistic Forecasting)을 적용하고 예측 불확실성을 분석 경험
