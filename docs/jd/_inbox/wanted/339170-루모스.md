## 소개

루모스는 국가사업 행정·재무·문서 문제를 AI로 해결하는 GovTech 기업입니다. 국가사업의 탐색,신청,수행,사업비 집행,최종 보고 전 과정을 AI Agent로 자동화하고 있습니다.

고객사 500개+ / 설립 3년차, 설립 첫 해 BEP 달성, 매년 2배 이상 성장
NICE평가정보 등 대기업, 지원사업 주관기관과 협업 중
해외 시장 진출 준비 중 (일본, 싱가포르, 미국)

지금은 중소기업의 국가사업이라는 가장 복잡하고 어려운 문제부터 풀고 있지만, 루모스의 최종 목표는 여기서 끝나지 않습니다. 루모스는 국가사업 Agent를 넘어, 중소기업의 모든 데이터를 이해하고 경영·행정·재무까지 자동으로 처리하는 AGI 기반 기업 운영 OS로 발전하고자 합니다.

팔란티어가 데이터를 통해 멀리 보게 해주는 회사라면, 루모스는 기업이 지금 당장 마주한 문제를 분명히 보이게 만드는 AI를 만듭니다.

이 포지션은 일부 기능만 맡는 역할이 아닙니다. 국가사업·재무·행정 문서를 이해하고 판단하는 AI Agent를 문제 정의부터 구조 설계, 실제 고객 사용까지 함께 만드는 AI/ML 엔지니어 포지션입니다. 시니어 AI 엔지니어(네이버 AI 리드 출신)와 협업하며, 상용 AI API 기반 시스템 설계부터 자체 모델 학습·실험·서빙까지 — Full Stack AI Engineer로 성장하는 자리입니다.

## 주요업무

루모스 AI Agent 개발 — 국가사업·재무·행정 문서를 이해하고 판단하는 Agent 설계
LLM 기반 문서 자동화 모델 개발 및 최적화 (파인튜닝, 평가, 개선)
VLM·LLM을 활용한 문서 분석 및 생성 — 법규·지침·재무 데이터를 AI가 판단 가능한 구조로 변환
RAG 파이프라인 설계 및 개선 (chunking, retriever, reranker, 평가 구조 포함)
실제 사용자가 쓰는 AI 시스템의 설계부터 서빙까지 — 고객 문제를 빠르게 프로토타이핑하고 실제 서비스로 연결
AI 코딩 도구를 적극 활용해 백엔드/프론트엔드까지 직접 만들고 클라우드에 배포
"왜 이 Agent 구조가 맞는지"를 팀과 함께 정의
