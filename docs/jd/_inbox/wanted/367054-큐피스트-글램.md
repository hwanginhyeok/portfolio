## 주요업무

[팀 소개]
큐피스트 QA팀은 각자가 하나의 브랜드를 맡아, 서비스 흐름과 사용자 경험의 품질을 함께 책임지는 팀입니다.

데이팅 서비스는 단순한 기능의 조합이 아닙니다.
가입, 인증, 추천, 대화, 결제, 운영 정책이 하나의 흐름으로 이어질 때 비로소 완성됩니다.

그래서 저희의 QA는 기능 단위 검증에 머물지 않습니다.
실제 사용자의 여정 안에서 어떤 이탈과 불편이 생길 수 있는지,
그 흐름을 먼저 그리는 것부터 시작합니다.

기획 단계부터 리스크를 검토하고,
빠른 배포 환경에서도 핵심 동선과 영향 범위를 중심으로 우선순위를 세웁니다.
글로벌 확장에 맞춰 국가별 정책, 인증, 결제, 운영 이슈까지 함께 살피며
각 브랜드에 더 안정적이고 자연스러운 경험을 만들어가고 있습니다.

내가 맡은 브랜드를 깊이 이해하고,
기능 너머 서비스 전체의 품질을 함께 만들어가고 싶은 분을 기다립니다.

[주요 업무]
• 글로벌 AI Chat 서비스(웹/앱)의 QA 테스트를 계획하고 실행해요
• 테스트케이스를 설계·작성하고, 릴리즈 전 체계적인 테스트 수행으로 서비스 품질 기준을 잡아요.
• 결함(Bug)을 발견하면 리포트를 작성하고 추적·관리하며, 재현 시나리오와 원인 분석으로 빠른 해결을 도와요.
• 개발·기획팀과 긴밀하게 협업하며 요구사항 검토 단계부터 품질 관점의 피드백을 드리고 서비스 완성도를 높여요.
