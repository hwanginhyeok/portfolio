## 소개

[ 웨어러블에이아이 소개 ]
웨어러블에이아이는 공항, 리조트, 항만, 조선소, 공장 등 다양한 이동 주체가 얽혀 움직이는 SPM(Special-Purpose Mobility, 특수목적모빌리티) 환경에 맞춰,
AI 월드모델 기반 인식·예측, Proactive Driving, 독립적인 Safety Architecture, 자체 설계한 로봇을 하나로 결합해, Plug-and-Play 방식의 풀스택 로보틱스 플랫폼을 만듭니다.

[직무소개]
본 포지션은 whereable.ai가 SPM(Special Purpose Mobility) 환경—조선소, 항만, 물류 야드, 리조트, 대형 캠퍼스 등—에 배치하는 자율주행 모빌리티의 소프트웨어와 하드웨어가 실제 차량 위에서 안정적으로 함께 동작하도록 센서, Actuator, 제어기, 배선, 시스템 소프트웨어를 통합하는 역할입니다.
소프트웨어 개발 역량과 함께 간단한 회로 구성, 납땜, 커넥터 작업, 부품 조립, 테스트 Jig 제작, MCU 펌웨어 작성 등 Mechatronics 현장 역량을 활용합니다.
실제 하드웨어를 손으로 다루며 문제를 재현하고, 임베디드 펌웨어와 실시간 제어 로직을 직접 개발해 소프트웨어와 전장·기구 이슈를 연결해 제품의 통합 완성도를 높일 분을 찾고 있습니다.

## 주요업무

[주요 업무]

1. 센서·Actuator 시스템 통합
• LiDAR, 카메라, IMU, 모터, 버튼, 디스플레이 등 주요 부품을 차량 시스템에 통합
• 4륜 독립 조향(4WIS)·4륜 독립 구동(4WID) 플랫폼의 개별 휠 조향·구동 제어기와 Drive-by-Wire 인터페이스를 통합하고 검증
• 센서 장착, 배선, 통신 설정, 드라이버 실행, 데이터 수집까지 이어지는 통합 절차 수행
• AI Compute(NVIDIA Orin 등)와 물리적으로 분리된 Safety Board 간 통신 배선·인터페이스를 통합하고 역할 분리가 유지되는지 확인

2. 시스템 소프트웨어 및 펌웨어 개발
• 센서 드라이버, 통신 인터페이스, 데이터 수집 도구, 상태 모니터링 도구 개발 및 개선
• C++, Python, Linux 환경에서 하드웨어 제어와 데이터 처리 코드 작성
• STM32, ESP32 등 MCU 대상 펌웨어와 실시간 제어 로직을 직접 설계·구현하며, 4WIS/4WID 개별 휠 제어의 응답속도(latency)와 Jerk 최소화를 고려해 구현
• ROS 2 기반 Node, Topic, Message 구성 지원 및 하드웨어 이상 상태를 소프트웨어가 감지·기록하도록 진단 로직 개선

3. 간단한 회로 구성 및 전장 작업
• Breadboard, 만능기판, 간단한 PCB를 활용한 테스트 회로 구성
• 전선 압착, 납땜, 커넥터 조립, 케이블 라우팅, 기본 하네스 제작 수행
• 멀티미터, 전원공급기, Oscilloscope 등 기본 계측 장비를 활용한 전기적 확인
• 전원, 접지, 신호선, 통신선 문제를 안전하게 점검하고 개선안 제안

4. 프로토타입 조립 및 테스트 Jig 제작
• 브라켓, 센서 마운트, 전장 박스, 케이블 고정 구조 등 간단한 조립 작업 수행
• 반복 테스트를 위한 테스트 Jig, 임시 고정 구조, 간단한 부품 홀더 제작 지원
• 조립 중 발생하는 간섭, 체결, 열, 진동, 유지보수성 문제를 발견하고 기록
• 기구·전장 엔지니어와 협업하여 프로토타입의 조립성과 테스트 편의성 개선

5. 통합 검증 및 문서화
• 센서 데이터 수집, 구동계 동작, 전원 안정성, 통신 상태를 확인하는 통합 테스트 수행
• 하드웨어 변경 이력, 배선 구조, 드라이버 설정, 테스트 결과를 문서화
• 반복적으로 발생하는 통합 이슈를 체크리스트와 표준 작업 절차로 정리
• Perception, Localization, Motion Planning, 하드웨어 팀과 통합 이슈를 공유하고 해결
