## 소개

Trillion Labs는 산업의 미래를 움직이는 AI를 만듭니다.
Trillion Labs는 발전소와 AI 데이터센터를 비롯한 산업 현장을 위한 파운데이션 모델, 에이전틱 AI 시스템, 
그리고 AI 인텔리전스 인프라를 직접 개발합니다. 

최전선의 AI 연구를 실제 산업에 적용 가능한 기술로 연결하여 연구부터 인프라, 제품, 
사업화까지 전 과정을 직접 만들어가며, 복잡한 기술을 고객과 투자자, 정부 기관, 그리고 팀원들이 
이해하고 공감할 수 있는 가치로 바꿔 나갑니다.

Software Engineer, AI Infrastructure는 대규모 모델을 더 빠르게 학습하고, 
그 결과를 안정적으로 제품화할 수 있는 환경을 만듭니다

모델 개발 과정에서 반복되는 작업을 자동화하고, 학습 / 평가 / 배포에 필요한 도구와 인프라를 구축하여
모델이 실제 고객이 사용하는 제품으로 이어지도록 제품화에 필요한 기술적 기반을 만듭니다.

## 주요업무

모델 개발 플랫폼과 인프라를 만듭니다. 

데이터 관리, 학습, 실험, 평가, 배포 등 모델 개발 과정에서 반복되는 작업을 표준화하고 자동화합니다. 
모델을 개발하는 구성원들이 인프라나 운영 문제에 시간을 쓰지 않고 모델 자체에 집중할 수 있도록 내부 도구, 
자동화 시스템, 모니터링 환경을 만들고 운영합니다.

모델을 실제 제품으로 구현합니다.

개발된 모델을 고객이 실제로 사용할 수 있는 제품 또는 서비스로 구현합니다. 
프로토타입 단계에 머무르지 않고, 배포와 운영까지 고려해 안정적인 소프트웨어로 발전시킵니다.
