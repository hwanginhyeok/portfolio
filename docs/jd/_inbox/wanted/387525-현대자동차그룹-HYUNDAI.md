## 소개

• 이기종 시스템 간 통신 아키텍처 설계 및 통합

• Real-time OS Task 관리 및 아키텍처 개발

• 사용자 인터페이스 기반 로봇 운용 환경 구축
• 로봇 행동/작업 관리자 개발
• 강화학습·모방학습 기반 로봇 제어 프레임워크 구축
• VLA 등 최신 AI 학습 기반 로봇 제어 기술 적용을 위한 시스템 구축
