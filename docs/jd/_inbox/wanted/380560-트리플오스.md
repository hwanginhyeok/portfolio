직무 소개 | Backend / Infra Engineer

트리플오스의 백엔드/인프라 엔지니어는 서비스 개발과 인프라 운영을 균형 있게 담당합니다. Kotlin/Spring Boot 기반의 백엔드 개발부터 AWS·Kubernetes 기반의 클라우드 인프라 구축과 운영까지, 서비스가 만들어지고 사용자에게 안정적으로 전달되는 전 과정을 책임지는 포지션입니다.

여러 AI 서비스를 동시에 빠르게 만들고 검증하는 팀 특성상, 기능 구현에만 머무르지 않고 아키텍처 설계, 배포 자동화, 서비스 안정성까지 폭넓게 고민할 수 있는 분과 함께하고 싶습니다. 개발과 인프라 어느 한쪽에 치우치지 않고 두 영역을 오가며 성장하고 싶은 분에게 잘 맞는 자리입니다.
