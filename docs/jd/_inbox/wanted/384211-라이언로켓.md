## 주요업무

이미 검증된 뷰티 컨설팅을 다음 단계로 키웁니다.

• 컨설팅 개편 — 지금의 컨설팅 품질과 경험을 다시 설계합니다. 후기 · CS를 직접 읽고 제품에 반영합니다.
• 신규 컨설팅 기획 — 트렌드를 읽고 헤어 · 의상 · 웨딩 다음의 새 컨설팅 상품을 0부터 기획하고 출시합니다.
• 상세페이지 · 퍼널 — Figma로 직접 만들고, 지표를 개선합니다.
• CAC · 글로벌 · 매출 천장 — 고객 획득 비용을 낮출 수 있는 가설을 수립하고 글로벌로 확장합니다.
• 데이터 판정 — Mixpanel · Claude Code 등으로 결과를 판정하고, 다음 개선 사이클을 돌립니다.
• 검증된 실험은 반영하고, 실패한 실험은 학습으로 남깁니다.
