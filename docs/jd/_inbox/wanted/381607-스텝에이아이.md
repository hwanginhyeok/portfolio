## 소개

AI로 만들고, 현장에서 증명하고, IP로 전환합니다.
현재 운영 중인 서비스의 성장과 신규 프로젝트 확장으로 개발팀을 증원합니다.

## 주요업무

대규모 공개 데이터를 수집·구조화해 기업에 맞춤 추천하는 B2B AI SaaS를 함께 만들 풀스택 개발자를 찾습니다. 이미 유료 고객이 결제하며 쓰고 있는 운영 서비스이고, 매일 도는 수집·추출·추천·알림 파이프라인이 제품의 핵심입니다.

• FastAPI 기반 비동기 API 서버의 기능 개발과 운영 (데이터 수집·추출·추천·알림·결제 도메인 전반)
• 작업 큐(Redis)와 cron 잡 위에서 도는 대용량 배치 파이프라인 설계·개선
• PostgreSQL 스키마 설계와 마이그레이션, 대용량 데이터 환경에서의 쿼리 최적화
• Next.js·TypeScript 기반 사용자 웹과 운영자 콘솔(admin) 화면 개발
• LLM 파이프라인 개선 (프롬프트 설계, 구조화 출력, 결과 검증, 품질 평가, 비용 최적화)
• 비정형 문서 파싱과 OCR 파이프라인 정확도 개선
• 멀티채널 알림 발송(이메일·메신저)과 구독·크레딧 결제 도메인 개발
• 클라우드 컨테이너 서비스 배포·운영과 로깅·에러 트래킹 기반 장애 대응
• 명세가 불완전한 요구사항을 구조로 세우고, 결정을 문서로 남기는 일
