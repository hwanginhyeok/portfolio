## 소개

LLM 기술로 AI 캐릭터에 생명력을 불어넣고, 전 세계 사용자가 몰입하는 대화 경험을 함께 만들어갈 당신을 기다립니다.”

안녕하세요, AI 캐릭터 채팅 서비스 Babechat입니다.

우리는 사용자와 AI 캐릭터 간의 경계 없는 소통을 통해 새로운 즐거움과 관계의 가능성을 만들어가고 있습니다.

Babechat의 핵심인 LLM 기반 대화 시스템을 설계하고 개발할 AI 엔지니어를 찾습니다.

다양한 LLM을 실제 서비스에 연결하고, 프롬프트와 대화 컨텍스트, 기억 시스템을 고도화하여 캐릭터의 개성과 관계가 자연스럽게 이어지는 대화 경험을 만들어갑니다.

기술을 구현하는 데서 나아가, 사용자의 반응과 데이터를 바탕으로 대화 품질을 지속적으로 개선할 분을 모시고자 합니다.

## 주요업무

LLM 기반 서비스 개발

다양한 LLM API를 활용해 AI 캐릭터 대화 시스템을 설계하고 개발해요.
모델별 특성을 비교하고, 서비스 목적에 맞는 모델 선택과 연동 방식을 개선해요.
스트리밍 응답, API 오류 대응, 캐싱 등을 통해 응답속도와 안정성, 사용 비용을 최적화해요.

프롬프트 & 대화 컨텍스트 고도화

캐릭터의 설정과 말투, 세계관을 일관되게 유지하도록 프롬프트를 설계하고 개선해요.
긴 대화에서도 중요한 사건과 사용자와의 관계를 기억할 수 있도록 대화 요약 및 메모리 시스템을 개발해요.
RAG를 활용해 캐릭터 설정과 과거 대화에서 필요한 정보를 검색하고, 적절한 맥락에 반영해요.

대화 품질 개선 & 기능 확장

캐릭터 일관성, 기억 정확도, 반복 표현 등 대화 품질을 평가하는 기준과 테스트 체계를 만들어요.
사용자 피드백과 대화 데이터를 바탕으로 문제를 분석하고, 실험을 통해 개선 효과를 검증해요.
Function calling, Tool use 등을 활용해 캐릭터의 상호작용과 서비스 기능을 확장해요.
