## 소개

"Global Digital Marketing에 대한 진정성 있는 관심과 열정만 가지고 오십시오. '디지털 마케팅의 Only One 전문가'로 성장할 수 있도록 아티언스가 적극적으로 돕겠습니다."

아티언스(Artience)는 2009년에 시작한 글로벌 디지털 마케팅 전문 기업으로 최근 3년간 3배 이상 성장하였습니다. 하지만 앞으로 새로운 가능성을 보고 도전해야 할 분야는 아직 너무나 많습니다. 

전 세계 디지털 미디어를 활용하여 클라이언트의 글로벌 고객에게 원하는 메시지를 생성하여 전달하는 동시에 측정된 결과를 분석, 최적화하여 제공함으로써 비즈니스 성과를 극대화하는 일을 하고 있습니다.

아티언스와 함께 새로운 가치 창출을 위한 여정에 동행할 새로운 아티언서를 찾고 있습니다.

## 주요업무

1. AI 서비스 및 내부 Product 개발 실무 수행
• 생성형 AI 기반 사내 서비스 및 업무 자동화 도구 개발
• OpenAI, Anthropic, Gemini 등 상용 LLM API를 활용한 기능 개발
• 프론트엔드/백엔드 개발을 통한 AI 서비스 화면 및 기능 구현

2. RAG 및 사내 지식 기반 AI 시스템 구축
• 사내 문서, 업무 가이드, 보고서, 데이터 등을 활용한 RAG 시스템 설계 및 구현
• 문서 수집, 전처리, 임베딩, 검색, 응답 생성 등 RAG 파이프라인 개발
• Vector DB, Embedding Model, LLM API를 활용한 질의응답 기능 구현
• 사내 업무 지식에 기반한 검색형 AI 서비스 개발
• AI 응답 정확도, 검색 품질, 문서 참조 구조 개선

3. AI Agent 및 업무 자동화 개발
• 메일 분류, 회의록 요약, 리포트 QA, 문서 생성 등 업무형 Agent 개발
• Tool Calling, Function Calling, Workflow Automation 기반 기능 구현
• 사용자의 요청을 여러 단계로 처리하는 자동화 시나리오 개발
• OpenClaw 및 유사 Agent 프레임워크 기반 사내 AI 에이전트 구축

4. 서비스 운영 및 기술 문서화
• AI 서비스 오류, 성능, 사용성 이슈 개선
• API 비용, 응답 속도, 안정성, 품질 모니터링
• 설치 가이드, 운영 가이드, 기술 문서 작성
