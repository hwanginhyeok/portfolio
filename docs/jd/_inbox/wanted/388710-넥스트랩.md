## 소개

AI 융합된 각종 품질 측정 하드웨어 장비 개발 (네트워크 품질 측정기, STB 자동화 테스트 장비, X-ray 장비 등)

## 주요업무

넥스트랩의 Industrial Test & Measurement 제품 하드웨어 개발 엔지니어로서, 통신품질 테스트 디바이스 개발과 X-Ray 검사장비 개발을 담당합니다.
• 디바이스 개발 : WiFi, 이더넷 등을 연결하여 각종 품질을 테스트하는 디바이스의 회로개발을 담당합니다.
• 장비 개발 : X-Ray 검사장비의 전장을 개발하고, 내부 하드웨어 모듈들의 사양을 선정합니다.
• 외주관리 : 외부 전문업체와 함께 개발을 수행할 경우 업체에 사양을 제시하고, 진행상황을 관리합니다. 또한 외주 양산업체의 생산을 관리합니다.
