## 소개

우리는 이미지·비디오 ​생성 ​모델 ​기반의 World ​Model을 연구·개발하며, 이를 로보틱스 ​환경에 ​적용합니다. 
DiT/Flow ​Matching 기반 Video ​Generation 모델과 ​Action-conditioned ​World Model의 ​아키텍처를 ​이해하고, ​직접 설계·구현·개선합니다. 단순한 ​시각적 ​그럴듯함을 넘어 Metric ​Scale과 ​Geometric ​Consistency한 생성 기술을 ​통해, 로봇이 ​실제로 ​신뢰하고 조작에 ​활용할 수 ​있는 ​환경을 구축합니다. 또한 ​생성 모델을 ​통해 비전 AI 학습용 합성 데이터를 생산하여 실데이터 부족 문제를 해결합니다.

## 주요업무

• Geometry-grounded/Metric-scale video generation 연구: 생성 결과가 실세계 스케일·3D 구조와 정합하도록 하는 Conditioning 및 학습 기법
• 대규모 Video Generation Foundation Model 로보틱스 도메인 적용
• 로봇 조작을 위한 World Model 설계 및 구현: 생성형 아키텍처 기반의 Action-conditioned future prediction
• 비전 AI 학습용 합성 데이터 생성 모델 개발
• Domain Randomization/Synthetic Data 파이프라인 구축 및 Downstream Task(Detection, Segmentation, Pose Estimation) 성능 검증
• 정책 학습, 평가를 위한 생성형 시뮬레이션 환경 연구: Real2Sim 파이프라인 연계
• 생성 데이터 및 예측 결과의 품질 평가 지표 설계, 실패 케이스 분석 및 일반화 성능 향상
