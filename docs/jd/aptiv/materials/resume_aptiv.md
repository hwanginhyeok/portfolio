## 요약

제품을 양산 라인으로 넘겨본 개발자입니다.

GT-SS500(48V 전동 자율주행 방제기)에서 **APQP Phase 2~3을 운영**해 DFMEA를 Step 1에서 7까지
돌려 AP=H 5건을 도출했고, **BOM 132항목 중 재고 미확보 23건**을 양산 일정이 깨지기 전에
찾아냈습니다. 현장 이슈 37건 중 14건을 직접 처리하며 **NCR 27건**을 냈고, 근본원인 추적
4건은 설계변경까지 이어졌습니다.

시험 장비는 사지 않고 직접 설계했습니다 — **다이나모미터 토크제어 비선형성 0.008%**,
팬 벤치 풍속 **+57%**, 범퍼 시험대 정지거리 **0.082 m**.

직전에는 **12V 400W 차량용 전동오일펌프(EOP)** 국책과제를 완료했습니다. 차량 열관리
액추에이터의 제어·검증·양산 이관을 직접 수행했고, 특허 2건이 여기서 나왔습니다.

**핵심어**: 양산 이관 · APQP · DFMEA · NCR · BOM · 공정 검증 · 현장 RCA · 자동차 전장

**2025.01 ~ 현재**

GT-SS500 풀사이클 — 알고리즘부터 양산 초도 출하까지.

| 영역 | 수행 내용 |
|------|-----------|
| **양산 이관** | APQP Phase 2~3 운영. DFMEA #201/#210 Step 1~7 (AP=H 5건). Boundary Diagram + Assembly 재편. 양산 초도 16pcs + 대차 2 + Spare 2 생산계획 수립 |
| **부품·일정 리스크** | BOM 132항목 관리, **재고 미확보 23건 사전 식별** |
| **현장 이슈** | 37건+ 트래킹 중 직접 담당 14건, **NCR 27건** |
| **근본원인 추적 4건** | MCB 전해부식(#204) · LCD 상태머신(#79) · **펌프 동파 오링**(5호기 동시 발생 → 오링 가공불량(depth·wall thickness) 규명 → 설계변경 + 20개 발주) · GND 노이즈(FM-6 / PFMEA P-15) |
| **설계변경 관리** | CAN DBC 4종 직접 작성·관리, **BREAKING CHANGE 4건 사전 검출** |
| **시험 체계** | 다이나모 / 펌프 벤치 / 팬 벤치 / 범퍼 시험대 **단독 설계**. CAN 정합성 체크리스트 3차 반복 프로토콜 표준화 |
| **검사 기준** | IQC / OQC 검사 가이드 작성 |
| **정량 성과** | 팬 풍속 7.9 → **12.4 m/s (+57%)** · 범퍼 정지거리 **0.082 m** / 피크 308 A / 정착 467 ms (3 km/h) · 펌프 3시료 선형관계 규명(명판 스펙 허위 검증) |
| **대외 대응** | 혁신제품 실사 4/9 대응(#205), 농진원 대응, 6개 팀 cross-functional |
