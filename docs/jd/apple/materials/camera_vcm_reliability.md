## 1. Camera Module 기본 구조

### 1.1 스마트폰 카메라 모듈 구성요소

```
[Lens Assembly]
     ↓
[VCM (Voice Coil Motor)]   ← AF 구동
     ↓
[Image Sensor (CMOS)]
     ↓
[ISP (Image Signal Processor)]
     ↓
[FPC / PCB 연결]
```

| 컴포넌트 | 역할 | 주요 파라미터 |
|----------|------|--------------|
| **Lens Assembly** | 광학 초점 형성 | 초점거리, F값(조리개), 배율, MTF |
| **VCM (Voice Coil Motor)** | AF(Auto Focus) 렌즈 이동 | 스트로크(mm), 응답속도(ms), 전류소비(mA) |
| **CMOS Image Sensor** | 광을 전기신호로 변환 | 화소 크기(μm), Dynamic Range, SNR |
| **OIS (Optical Image Stabilizer)** | 손떨림 보정 (VCM 변형) | 보정 각도(°), 응답속도 |
| **FPC (Flexible PCB)** | 전기 연결 | 굴곡 횟수 내구성, 저항값 |
| **IR Filter** | 적외선 차단 | 투과 파장 범위 |

### 1.2 VCM 상세 구조 (AF 핵심 부품)

**Voice Coil Motor 동작 원리**:
- 코일에 전류 → 자기력 발생 → 렌즈 홀더 이동 (F = BIL)
- Hall Sensor 또는 MEMS 위치 센서로 폐루프 제어
- 스프링 서스펜션으로 복원력 제공

```
[Magnet]
[Coil + Lens Holder] ← 전류 → 이동
[Spring Suspension]  ← 복원력
[Hall Sensor]        ← 위치 피드백
```

**주요 스펙 (iPhone 급 참고)**:
- 스트로크: 0.3~0.5mm (AF 범위)
- 응답속도: 10~50ms
- 구동 전류: 50~200mA
- 내충격: MIL-STD-810 수준 (1.2m 낙하)

### 1.3 OIS 구조 (손떨림 보정)

- **Lens Shift 방식**: VCM 4개로 렌즈를 X/Y축 이동
- **Sensor Shift 방식**: 이미지 센서 자체를 이동 (더 효과적)
- 각속도 센서(자이로) + VCM 피드백 제어
- 보정 범위: ±1~2°, 응답속도: 1~5ms

## 2. 주요 고장 모드 (Failure Modes)

### 2.1 VCM 고장 모드

| 고장 모드 | 원인 | 황인혁 경험 매핑 |
|-----------|------|-----------------|
| **코일 단선 / 층간 단락** | 과전류, 열화, 굴곡 피로 | IGBT 본드와이어 lift-off (P-01) — 동일: 전기적 연결 열화 검출 |
| **스프링 피로 파괴** | 반복 사이클, 낙하 충격 | 기계적 피로 — ALT 설계 (P-05 bearing wear) |
| **홀센서 드리프트** | 온도, 자기장 변화 | 센서 신뢰성 — multi-sensor PHM |
| **자석 감자(Demagnetization)** | 고온, 역자기장 | IPMSM 영구자석 감자 (P-03, T-01) — 동일 현상 |
| **이물 침입 (먼지/수분)** | 밀봉 불량 | 방수 설계 — EOP CAN connector 방수 경험 |

### 2.2 렌즈 고장 모드

| 고장 모드 | 원인 |
|-----------|------|
| **코팅 박리** | UV 열화, 습도, 온도 사이클 |
| **렌즈 크리프 / 변형** | 고온 장기 노출 |
| **충격 파손** | 낙하, 진동 |
| **헤이즈 (haze)** | 수분 침투, 화학 오염 |

### 2.3 Image Sensor 고장 모드

| 고장 모드 | 원인 |
|-----------|------|
| **Hot Pixel / Dead Pixel** | 방사선, 과전압, ESD |
| **노이즈 증가 (Dark Current)** | 고온 열화 |
| **FPC 접점 불량** | 굴곡 피로, 납땜 열화 |

## 3. Reliability 이론 적용

### 3.1 가속수명시험 (ALT) — 황인혁 경험 → 카메라 적용

**기존 경험 (RESUME §6.2)**:
- P-04: PV 폴리머 ALT — damage summation 접근법
- P-05: IPMSM ALT — dual sensor architecture (전류·온도·진동·변위)

**카메라 모듈 ALT 설계 원리**:

| 스트레스 인자 | 가속 조건 | 해당 고장 모드 |
|--------------|----------|--------------|
| **온도** | HTOL (85°C, 1000h) | 코팅 박리, 렌즈 크리프, 자석 감자 |
| **온도 사이클** | -40°C ↔ +85°C, N사이클 | FPC 피로, 접착제 박리 |
| **진동** | MIL-STD-810G Method 514 | 스프링 피로, 접점 불량 |
| **낙하 충격** | 1.2m 낙하 × 방향 | 스프링 파괴, 렌즈 파손 |
| **습도** | THB (85°C/85%RH) | 코일 부식, 코팅 박리 |

**황인혁 브리지 설명 (면접 시)**:
> "대학원에서 IPMSM ALT에서 사용한 접근법 — 스트레스 인자를 식별하고, Arrhenius 또는 power law로 가속 인자를 계산하고, Weibull 수명 분포로 신뢰도 추정 — 은 카메라 VCM ALT에 동일하게 적용됩니다. 대상 컴포넌트가 다를 뿐 방법론은 동일합니다."

### 3.2 DFMEA 적용 — VCM 예시

**황인혁 DFMEA 경험**: GT-SS500 4건 (MCB 전해부식·상태머신·오링·노이즈)

**VCM DFMEA 예시 (AP=H 기준)**:

| 기능 | 고장 모드 | 고장 영향 | S | 원인 | O | 현행 관리 | D | RPN | AP |
|------|-----------|-----------|---|------|---|-----------|---|-----|----|
| AF 구동 | 코일 단선 | AF 불가 (고객 불만) | 8 | 과전류 / 피로 | 4 | 전류 제한 회로 | 4 | 128 | H |
| 위치 유지 | 스프링 파손 | 렌즈 흔들림 | 7 | 낙하 충격 | 3 | 낙하 시험 | 5 | 105 | M |
| AF 정확도 | 홀센서 드리프트 | 초점 오류 | 6 | 온도 의존성 | 5 | 캘리브레이션 | 4 | 120 | H |

### 3.3 PHM 적용 — 카메라 모듈 Health Monitoring

**황인혁 PHM 경험**: Multi-sensor PHM (phase current · 온도 · shaft displacement · vibration)

**카메라 모듈 PHM 적용 가능 신호**:

| 센서 | 측정값 | 진단 목표 |
|------|--------|----------|
| 전류 센서 | VCM 구동 전류 | 코일 저항 변화 → 열화 감지 (P-01 IGBT 동일 원리) |
| 홀 센서 | 렌즈 위치 | 스트로크 감소 → 스프링 피로 감지 |
| 온도 센서 | 모듈 온도 | 열화 가속 모니터링 |
| 자이로 | 진동/각속도 | OIS 성능 저하 감지 |

### 3.4 수명 예측 — Damage Summation 적용

**황인혁 경험 (P-04 Solar Energy 2024)**:
- damage summation → 변동 환경하 수명 추정
- Miner's Rule 기반

**카메라 모듈 수명 예측 적용**:
```
총 손상(D) = Σ (ni/Ni)

ni: 실제 운영 조건에서의 사이클 수
Ni: 해당 스트레스 조건에서의 파손 사이클 수

D ≥ 1.0 → 수명 만료
```

예: 스마트폰 하루 100회 AF 구동 → 3년 = 110,000회
    ALT에서 50°C 조건 500,000회까지 무고장 → 가속 인자 계산 → 수명 예측

## 4. 면접 준비 — 예상 Q&A

### Q1: "카메라 VCM을 어떻게 신뢰성 테스트하겠는가?"

**답변 구조**:
1. **고장 모드 식별**: DFMEA로 코일 단선/스프링 피로/홀센서 드리프트 도출
2. **스트레스 인자 매핑**: 온도/진동/충격/습도 → 고장 모드 연결
3. **ALT 설계**: HTOL(85°C/1000h) + 열충격(-40↔85°C) + 낙하시험 설계
4. **합격 기준 정의**: Weibull B10 수명 > 필드 예상 수명 × 안전계수
5. **PHM 연계**: 전류 서명 분석으로 현장 열화 모니터링

**브리지 포인트**: "IPMSM ALT에서 정확히 이 과정을 수행했습니다 — 대상은 다르지만 방법론은 동일합니다."

### Q2: "ORT(Ongoing Reliability Testing)란 무엇이고 어떻게 운영하는가?"

- 양산 중 샘플링 → 가속 시험 → 필드 품질 트렌드 모니터링
- 황인혁 경험: APQP Gate Review + IQC/OQC 검사 + NCR 트래킹 → ORT와 동일 구조

### Q3: "FA(Failure Analysis) 프로세스를 설명하라"

**GT-SS500 MCB 전해부식 사례**:
1. 현상 관찰 (48V 전력단자 탄화)
2. 고장 모드 정의 (접촉저항 상승)
3. 근본원인 분석 (전해 부식 메커니즘)
4. 설계 변경 (IEC 60947-2 등급 교체)
5. 검증 (재현 시험 → 재발 0)

→ 카메라 FA에도 동일 5단계 적용
