### 연차별 워크 패턴 *(추정 — 드론 스타트업 일반 패턴 + 규모 75명·R&D 70% 기준)*

**1년차**: PX4 코드베이스 온보딩 (commander·ekf2·mc_att_control 3개 모듈 집중). 선배 PR 리뷰 보조. SITL에서 기능 검증. ESC/센서 설정 보조 업무. → 코드 50% / 리뷰·학습 30% / 시험 20%

**3년차 (모듈 오너)**: 모듈 1~2개 단독 소유 (예: DroneCAN 스택, 배터리 관리 로직). 설계 리뷰 주도. 신기체 보드 bring-up. 필드 시험 데이터 분석 → 버그 픽스 루프. → 코드 40% / 설계·리뷰 30% / 시험·필드 30%

**시니어**: 아키텍처 결정 (FCU ↔ Companion 인터페이스 설계). 신규 기체 플랫폼 FW 아키텍처. 주니어 온보딩. 방산 납품 인증 기술 대응. → 코드 25% / 설계·리딩 45% / 외부 대응 30%

### 협업 구조 *(추정 — 직원 75명, R&D 70%)*

```
FW 팀 ←→ AI/비전 팀: Companion에 보낼 setpoint 포맷·레이턴시 예산 합의
FW 팀 ←→ HW/기구 팀: 보드 bring-up, 전원 시퀀스, 온도 제약
FW 팀 ←→ 시험팀: SITL→HIL→필드 3단계. 필드에서 발견된 CAN 버그를 FW로 피드백
```

**FW↔AI 인터페이스 오너십**: *(추정)* 현재는 FW 팀이 OFFBOARD 모드 입력 규격 정의 후 AI 팀이 맞추는 구조 가능성 높음 → §E 역질문 #6으로 확인

## §C. 회사 문화 정성 시그널

### R&D 70%가 말하는 것

직원 75명 중 약 53명이 R&D. 매출 성장(+123%)과 수주(204억) 급등에도 영업/운영 인원을 크게 늘리지 않은 구조.
시사점: **"일단 기술로 증명"이 최우선 문화**. 기술 논거 없는 의견은 통하기 어려움. 엔지니어가 제품 방향에 직접 영향력.

### 황인혁 강점과의 정합

- **프로세스 미비 환경**: SS500에서 37건 이슈 분류·CAN 로그 직접 추출을 "누가 시켜서"가 아니라 스스로 했음 → 리소스 부족 환경에서 자기 주도로 일하는 패턴 이미 검증
- **빠른 성장 압박**: APQP Phase 2~3 + 임베디드 개발 동시 수행 — 양산 압력 속 실행 경험 있음
- **기술 기반 문화**: 수치와 데이터로 설득하는 방식이 이미 본인 스타일

## §E. 면접 역질문 6개 — "이미 아는 정보 + 한 단계 더"

**#1 — 중동 납품 양산 프로세스**
> "중동 계약 1,000만 달러 납품을 준비하시면서, DFMEA나 IQC 체계 같은 양산 품질 프로세스는 어느 단계까지 구축하셨나요? 방산 고객 요구 품질 기준이 저희가 상상하는 것보다 훨씬 엄격할 것 같아서요."

**#2 — IPO 후 FW 구조 변화**
> "기술성 평가 A/A를 통과하시고 상장 예비심사까지 청구하셨는데, IPO 이후 본격 양산 대응을 위해 FW 쪽 아키텍처나 CI/CD 파이프라인을 바꾸실 계획이 있으신가요?"

**#3 — 비전 AI와 FW 실시간 경계**
> "KAiDEN 250km/h 요격에서 엣지 AI 추론 레이턴시와 FW 400Hz 루프 사이 타이밍 예산을 어떻게 나누시나요? Companion에서 setpoint를 몇 Hz로 PX4에 보내시는지 궁금합니다."

**#4 — 중국 부품 없는 공급망 관리 비용**
> "NDAA 요건 충족을 위해 중국 부품을 전혀 안 쓰신다고 알고 있는데, 대체 공급망 관리 비용이 경쟁사 대비 얼마나 더 드나요? 미국 방산 시장 진입 시 이 비용이 실제 경쟁력이 되는 포인트가 어디인지 현장에서 느끼시는 게 궁금합니다."

**#5 — XAiDEN 군집 프로토콜**
> "XAiDEN 군집 자폭 드론에서 기체 간 통신이 두절됐을 때 충돌 회피는 어떻게 처리하시나요? 각 기체가 독립 판단인지, 아니면 편대 리더 방식인지 공개 범위 안에서 여쭤봐도 될까요?"

**#6 — FW ↔ AI 인터페이스 오너십**
> "FW 팀과 AI·비전 팀 사이에서 Companion → PX4 setpoint 인터페이스 설계는 어느 팀이 오너를 가져가시나요? 이 경계가 업무 협업에서 제일 복잡한 지점일 것 같아서요."
